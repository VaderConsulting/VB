Purpose : 	ActiveX component to add and remove scheduled tasks on local or remote machine
Installation :  Run setup.exe to install
Status :	It's a fully functional demo
Distrib.Status: Distribution is free
Website : 	http://www.etasoft.com  
Contact : etasoft@email.com
Version : 1.9

Extended description :
Using this ActiveX component add and remove scheduled tasks on local or remote machine. Add task triggers to run once, daily, weekly, on logon or system start. Scheduled Tasks component works with Task Scheduler service introduced in Windows 98/2000 and available in 95/NT with IE4. Task Scheduler Service will run tasks added with this component. Component does not require VB runtime.


Requires Windows 2000 (or Windows NT 4.0 with Internet Explorer 4.0 or later).
Requires Windows 98 (or Windows 95 with Internet Explorer 4.0 or later).
