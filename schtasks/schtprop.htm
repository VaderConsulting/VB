Scheduled Task component properties and methods


Program (in/out)
    name of application to be scheduled to run or
    any item that the Task Scheduler can execute.
    These items may include any of the following (as supported by the operating system
    on which the task will execute): Win32® applications, Win16 applications,
    OS/2 applications, MS-DOS® applications, batch files (*.bat), command files (*.cmd),
    or any properly registered file type

StartingDir (in/out)
    applications start in directory

Parameters (in/out)
    application startup parameters

Comment (in/out)
    comment

TargetComputer
    selects the computer that component operates on, allowing remote task management

Username (in/out)
    string that contains the name of the user account in which the item will run.
    The empty string may be used to specify current logged user

Password
    string that contains the name of the user password in which the item will run.

Creator (in/out)
    string that contains the name of task creator

StartYear, StartMonth, StartDay, StartHour, StartMinute
    date time when task will be triggered

EndYear, EndMonth, EndDay
    date when task trigger will be deactivated

MinutesInterval
    interval in minutes task will be triggered repeatedly

MinutesDuration
    interval in minutes task can be triggered repeatedly

DayOfTheWeek
    day of the week used in weekly trigger
   It is a bitmask

    0000 0001    1         Sunday
    0000 0010    2         Monday
    0000 0100    4         Tuesday
    0000 1000    8         Wednesday
    0001 0000    16         Thursday
    0010 0000    32         Friday
    0100 0000    64         Saturday

    If you want it to run only on weekdays :
    Monday + Tuesday + Wednesday + Thursday + Friday
    2 + 4 + 8 + 16 + 32 = 62

DayOfTheMonth
    day of the month used in monthly trigger

DontStartIfOnBatteries (default is True)
    don't start task if runs on batteries

KillIfOnBatteries (default is True)
    kill task if runs on batteries

TriggerType
    possible values are:
    TRIGGER_ONCE = 0,
    TRIGGER_DAILY = 1,
    TRIGGER_WEEKLY = 2,
    TRIGGER_MONTHLYDATE = 3,
    TRIGGER_MONTHLYDOW = 4,     // not supported
    TRIGGER_ON_IDLE = 5,
    TRIGGER_AT_SYSTEMSTART = 6,
    TRIGGER_AT_LOGON = 7

TaskItem
    index of task to retrieve

TaskName (out)
    task name retrieved with Enum method

WhichWeek
   specify week for a trigger
    possible values are :
    first week = 1
    second week = 2
    third week = 3
    fourth week = 4
    last week = 5

DeleteWhenDone
delete then task finishes execution

RunOnlyIfLogged
run only if user logged in interactive

StartOnlyIfIdle
start task only if idle (Windows 95 only)

RunIfConnectedInternet
implemented but not all Windows configrations support that

RestartOnIdleResume
resume task execution on idle

DaysInterval
to set daily trigger, for example every 3 days

WeeksInterval
to set weekly trigger

LastTimeRun
Last time scheduled task run

NextTimeRun
Next time scheduled task run

TriggerString
Text description of trigger displayed in Windows dialog box

Disabled
get/set disabled task flag

// Methods

ActivateTask(taskname)
    prepare to read (in/out) properties for task


CreateTask(taskname, failifexists)
    create task. Calls AddTrigger inside

    - taskname        is a name of new task
    - failifexists    if TRUE fails if task exists, if FALSE - overwrites existing task

EditTask(taskname)
    show dialogs to edit task

RemoveTask
    remove task from scheduled tasks
   
AddTrigger
    add additional trigger.
    Call this method if you want to add more triggers to already created task
    CreateTask call must be made before

Reset
    cleans and releases all used objects
    Component does automatic cleanup and user do not need to call this function
    unless there is special need to reinitialize component

Enum
    enumerate/retrieve all tasks

AddMonth
    add month to monthly trigger

GetTrigger(trigger_index)
    get trigger related data from task . ActivateTask should be called before this call

RemoveTrigger(trigger_index)
   remove existing trigger. ActiveTask should be called before this call

Run
    run task . Should be used with ActivateTask

Terminate
    terminate task . Should be used with ActivateTask

GetStatus(status)
    get status of running task
    SCHED_S_TASK_READY = 0
    SCHED_S_TASK_RUNNING = 1
    SCHED_S_TASK_NOT_SCHEDULED = 2
