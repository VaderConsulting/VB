DHCP Objects 1.0 Installation Notes

Welcome to Microsoft (MCS) DHCP Objects 1.0. This document will guide you through the steps necessary to complete the installation of the components and the documentation for DHCP Objects.

1. Installing the ActiveX Component

The DHCP Objects component file, called DHCPOBJS.DLL, should have already been copied to your hard disk. In order to use the component, you must register it with your system using the standard ActiveX Control registration tool, REGSRVR32.EXE.

2. Installing the Help Files and Documentation

The DHCP Objects help file is provided in HTML Help format and can be loaded by double-clicking on the file called DHCPOBJS.CHM. However, if you do not have HTML Help already installed on your system, you need to so by clicking here.

Accessing On-line Documentation

You can access the help file and documentation for DHCP Object on-line by clicking here (Microsoft only). You may want to add this link to your Favorites folder.
