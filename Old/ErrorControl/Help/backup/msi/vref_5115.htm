Microsoft Windows Installer

PatchInfo Property

The read-only PatchInfo property of the Installer object returns information about a patch.

Syntax

object.PatchInfo(Patch, Attribute)

Parts

object
Installer object
Patch
Specifies the patch code for the patch package.
Attribute
Specifies the the attribute to be retrieved.

Remarks

This property is not available with Windows Installer version 1.0.
