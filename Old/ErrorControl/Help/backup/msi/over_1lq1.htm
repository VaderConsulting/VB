Microsoft Windows Installer

Source Resiliency

Applications that rely on network resources for installation-on-demand are susceptible to source failures if the source location should change for any reason or become damaged. The Microsoft® Windows® Installer provides source resiliency for features that are installed on-demand by using a source list. The source list contains the locations searched by the installer for installation packages. The entries in this list can be network locations, Uniform Resource Locators (URLs), or compact discs. If one of these sources fails, the installer can quickly and seamlessly try the next.

The application developer does not need to incorporate any special information into the installer package to ensure source resiliency. Once the application is installed, the installer has the behavior of adding the last successfully used source as an entry in the source list. By default, this source is the location from which the installer package is initially installed, and is the same as the SourceDir property.

A system administrator can change the source list by applying a transform or by changing the SOURCELIST property from the command line or in the Property table.

The installer begins searching for a source by checking the most recently used source location in the source list. If this search fails, the installer searches the list of network sources, then media sources, and finally URL sources. System administrators can change this search order using the SearchOrder system policy. If these searches fail, the installer may present a browse dialog to the user to manually search for the source. A browse dialog is only presented if the current user is an administrator or if the installation will not be installed with elevated privileges. The machine administrator can change this default behavior through the use of the DisableBrowse policy or AllowLockDownBrowse policy. The browse dialog is not displayed if the user interface level is set to None. See MsiSetInternalUI for a description of the user interface levels. System administrators can prevent users from browsing to locate installer sources by setting the DisableBrowse system policy.

By default, Windows Installer version 1.0 includes removable media drives on all application source lists. Administrators can secure a managed installation with Windows Installer version 1.0 by setting the DISABLEMEDIA property and the DisableBrowse policy. This will prevent non-administrator users from installing with elevated privileges from a CD-ROM.

With Windows Installer version 1.1 and later, non-administrator users by default cannot install with elevated privileges from media. If the user is an administrator, or if the installation is not elevated, media is still included on the source list. An administrator can change this by using the AllowLockdownMedia or DisableMedia policies.
