Microsoft Windows Installer

CloseModule Function

The function CloseModule implements the CloseModule method of the Merge Object. This function closes the currently open Windows Installer merge module.

IMsmMerge::CloseModule 

HRESULT CloseModule();

Parameters

None

Return Values

Value Meaning
E_FAIL There was an error closing the module. The state of the IMsmMerge interface is now undefined.
S_FALSE No module was open.
S_OK The function succeeded.

Remarks

Closing a merge module will not affect any errors that have not been retrieved.
