Microsoft Windows Installer

PatchTransforms Property

The read-only PatchTransforms property returns the semi-colon delimited list of transforms that are in the specified patch package and applied to the specified product.

Syntax

object.PatchTransforms(Product, Patch)

Parts

object
Installer object
Product
Specifies the product code.
Patch
Specifies the patch code.

Remarks

This property is not available with Windows Installer version 1.0.
