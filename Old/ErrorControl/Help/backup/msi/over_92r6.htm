Microsoft Windows Installer

Installing from Terminal Server

Administrator and non-administrator users can perform installations from the Terminal Services console.

Setting the EnableAdminTSRemote policy on Windows Installer version 1.1 enables administrators to perform installations from Terminal Services client sessions. An administrator installing from a Terminal Services client-session can do administrative installations.

Non-administrators cannot do any installations from a client-session. For more information, see Terminal Services in the Platform SDK.
