Microsoft Windows Installer

FeatureCost Property

The FeatureCost property of the Session object returns the total amount of disk space (in units of 512 bytes) required by the specified feature and its parent features (up to the root of the Feature table). For each feature, the total cost is made up of the disk costs attributed to every component linked to the feature.

Syntax

object.FeatureCost(feature, costTree, state)

Parts

object
Session object
feature
Required string name of the feature item whose cost is to be retrieved.
costTree
Required portion of the feature tree branch to cost, one of the following:
Part to cost Value Description
msiCostTreeSelfOnly 0 Cost feature.
msiCostTreeChildren 1 Cost children features.
msiCostTreeParents 2 Cost parent features.

state
Required element that specifies the action state to use when determining the feature cost. For example, if msiInstallStateLocal is specified, FeatureCost returns the disk space required if the specified feature and all its parent features were to be installed locally.
Action state name Value Description
msiInstallStateLocal 3 Disk space required if the specified feature and all its parent features were to be installed locally
msiInstallStateSource 4 Disk space required if the specified feature and all its parent features were to be installed to run from source.
msiInstallStateDefault 5 If installed, the item is to be reinstalled in the same state.
