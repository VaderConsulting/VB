Microsoft Windows Installer

ReinstallMode ControlEvent

This ControlEvent allows the author to specify the validation mode or modes during a reinstall while keeping the present dialog box running.

Published By

This ControlEvent is published by the installer.

Argument

A string. See the REINSTALLMODE property for a list of possible values.

Action on Subscribers

None.

Typical Use

A PushButton control on a modal dialog box is tied to this event and the same button is also tied to a Reinstall control event immediately before it.
