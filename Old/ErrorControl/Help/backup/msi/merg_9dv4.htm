Microsoft Windows Installer

ICEM10

ICEM10 verifies that a merge module does not contain disallowed properties in the Property Table. The disallowed properties are the ProductLanguage, ProductCode, ProductVersion, ProductName, and Manufacturer properties, which are product specific.

Result

ICEM10 Posts an error when a merge module contains a disallowed property in the Property Table.

Example

ICEM10 posts the following error messages for a module containing the database entries shown below.

The property 'ProductLanguage' is not allowed in a merge module.
 
The property 'Manufacturer' is not allowed in a merge module.

Property Table (partial)

Property Values
Color Red
Manufacturer Microsoft
ProductLanguage 1033

To fix the errors, perform the following:

  1. Remove the 'Manufacturer' property from the Property table.
  2. Remove the 'ProductLangauge' property from the Property table.

Table Used During Execution

Property Table
