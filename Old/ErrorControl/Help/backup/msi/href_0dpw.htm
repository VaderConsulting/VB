Microsoft Windows Installer

ActionText ControlEvent

The installer uses this event to publish the name of the present action.

Published By

This ControlEvent is published by the installer.

Argument

None.

Action on Subscribers

The subscribers are shown when a new progress data arrives from the installer.

Typical Use

A Text control on a modeless dialog subscribes to this event using the text attribute to receive the name of the current action.
