Microsoft Windows Installer

SafeForScripting

If this per-machine system policy is set to "1", the installer does not prompt users when scripts within a Web page use the installer's automation interface. This practice may be useful for Web-based tools. Note that setting this policy allows the installation of applications without user knowledge.

Registry Key

HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\Installer
