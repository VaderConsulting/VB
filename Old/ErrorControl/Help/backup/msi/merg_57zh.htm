Merge Module Summary Information Stream

Every merge module is required to have a Summary Information Stream containing the following properties. These properties are basically the same as for an installation package, see the main topic for each property. For a list of all the summary information streams in merge modules see Merge Module Summary Information Stream Reference.

Summary information property Meaning in merge modules
Template Summary Property Lists numeric language identifiers for all languages supported by the module. The first language in the list is the default language of the module.
Revision Number Summary Property The unique GUID for this merge module.
Page Count Summary Property Minimum required installer version. Stored as an integer in the form: Major * 100 + minor.
Word Count Summary Property Enter 0 for this property. Note that in a merge module, files are always inside an embedded cabinet file regardless of the value of this property.
