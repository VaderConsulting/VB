Microsoft Windows Installer

InstallSFPCatalogFile Action

The InstallSFPCatalogFile action installs the catalogs used by Microsoft® Windows® Millennium Edition for Windows File Protection. InstallSFPCatalogFile queries the Component table, File table, FileSFPCatalog table and SFPCatalog table. Catalogs are installed if they are associated with a file in a component that is set for local installation or if they are associated with a file being repaired in a locally installed component.

Sequence Restrictions

The InstallSFPCatalogFile action must be sequenced before InstallFiles and after CostFinalize.

ActionData Messages

Field Description of action data
[1] Name of the catalog being installed.
[2] Name of the catalog this catalog's installation depends upon.

Remarks

A catalog the is dependent on another catalog that is installed after the parent catalog.

This feature is not available using Windows Installer versions 1.0 and 1.1.

Windows File Protection for Windows Millennium Edition is provided with Windows Installer version 1.2. For more information, see Windows File Protection on Windows Millennium Edition.
