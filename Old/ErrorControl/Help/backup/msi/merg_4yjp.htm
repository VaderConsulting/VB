How do I choose the default language of a multiple-language merge module?

The default language for a merge module is the language listed in the ModuleSignature table of the module before any language transforms are applied. This is also the first language listed in the Template Summary Property.

The default language for the module should be one of the most specific languages you support because the default language is always checked first, and if it satisfies the requested language, it is used, even if another language would be a better match. For example, if a module supports 1033 and 0, 1033 should be the default language. If 0 were the default language, it would always satisfy any request, so the 1033 transform would never be used, even if 1033 is the exactly language requested.
