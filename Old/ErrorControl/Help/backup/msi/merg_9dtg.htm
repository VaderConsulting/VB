Microsoft Windows Installer

ICEM04

ICEM04 verifies that the Merge Module's required empty tables are indeed empty. Failure to fix an error reported by ICEM04 can result in improper merging of the Merge Module.

Result

ICEM04 posts an error when the Merge Module's required empty tables are not empty

Example

ICEM04 posts the following error messages for a module containing the database entries shown below.

An empty FeatureComponents table is required in a Merge Module.
 
The Merge Module contains the 'ModuleInstallExecuteSequence' table. It 
must therefore have an empty 'InstallExecuteSequence' table.
 
Action 'CostInitialize' found in the AdvtExecuteSequence table. This 
table must be empty in a Merge Module

AdvtExecuteSequence Table (partial)

Action Sequence
CostInitialize 1

Contents of MergeModule (partial)

  • ModuleInstallExecuteSequence
  • ModuleAdvtExecuteSequence
  • InstallUISequence

Another possible error (not evident with the Merge Module example shown) is:

Feature-Component '[1].[2]' found in the FeatureComponents table. The 
FeatureComponents table must be empty in a Merge Module.

If a Merge Module contains a Module Sequence table, it must contain the corresponding empty Sequence table (regardless of whether or not the Module Sequence table itself is empty). For example, if the Merge Module contains the ModuleAdminExecuteSequence table, it must also contain an empty AdminExecuteSequence table.

The FeatureComponents table is required in all Merge Modules and must be empty.

To fix the errors, perform the following:

  1. Add an empty FeatureComponents table to the Merge Module.
  2. Add an empty InstallExecuteSequence table to the Merge Module.
  3. Remove the 'CostInitialize' action from the AdvtExecuteSequence table. This table must be empty in a Merge Module. Actions should only appear in the ModuleAdvtExecuteSequence table

Tables used during execution

  • FeatureComponents Table
  • Module*Sequence tables and corresponding *Sequence tables (for example, ModuleAdvtUISequence Table with AdvtUISequence Table.
