Microsoft Windows Installer

AddSource Method

The AddSource method adds a source to the list of valid network sources in the sourcelist.

Syntax

object.AddSource(Product, User, Source)

Parts

object
Installer object
Product
Specifies the product code.
User
User name for per-user installation; NULL or empty string for per-machine installation.
Source
Pointer to the string specifying the source.

Remarks

This property is not available with Windows Installer version 1.0.
