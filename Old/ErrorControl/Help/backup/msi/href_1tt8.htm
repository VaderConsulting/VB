Microsoft Windows Installer

Icon Control

This control displays a static picture of an icon. The background of the image is transparent.

Control Attributes

You can use the following attributes with this control. To change the value of an attribute using an event, subscribe the control to a ControlEvent in the EventMapping table and list the attribute's identifier in the Attribute column. Enter the Identifier of the ControlEvent in the Event column.

Attribute identifier Hexadecimal bit Description
Position Position of control in the dialog box.

Enter the control's width, height, and coordinates of the control's left corner into the Width, Height, X, and Y columns of the Control table. Use pixels for units of length and distance.
Text Contains the name of an icon stored in the Binary table or the handle to a icon loaded into memory at run-time.

To display an icon that is stored in the Binary table, do not set the ImageHandle attribute and enter the name of the image's record appearing in the Binary table into the Text column of the Control table record for this control.

To set the icon image at run-time, set the ImageHandle control attribute in the Attributes of the Control table. At run-time, the Text control attribute is the handle to an icon loaded into memory. The control must subscribe to a control event listed in the EventMapping table with the Text control attribute specified in the Attribute column.
Visible 0x00000000

0x00000001

 Hidden control.

Visible control.

Include this bit in the bit word of the Attributes column in the Control table to make the control visible or hidden upon its creation.

You can also hide or show a control by using the ControlCondition table.
Sunken 0x00000000

0x00000004

 Display the default visual style.

Display the control with a sunken, 3-D look.

Include these bits in the bit word in the Attributes column of the Control table.
ImageHandle 0x00000000

0x00010000

 See the description of the Text control attribute for this control. If the ImageHandle attribute is included in the Attributes column of the Control table, the Text control attribute contains a handle to an icon that is loaded into memory at run-time. If the ImageHandle attribute is not included in Attributes, the Text Control attribute is the name of the icon and must be authored into the Text column of the Control table. This name is a key into the record of the Binary table containing the icon image.
FixedSize 0x00000000

0x00100000

 Stretch the icon image to fit the control.

Crop or center the icon image in the control.

Include this bit in the bit word of the Attributes column of the Control table.

IconSize 0x00000000

0x00200000

0x00400000

0x00600000

 Load the first image.

Load the first 16x16 image.

Load the first 32x32 image.

Load the first 48x48 image.

An icon file can contain different size images of the same icon. Include the value of the appropriate bit word in the Attributes column of the Control table

If these bits are not set, the installer ignores the FixedSize attribute and the image is stretched to fit the control rectangle. If both the IconSize bits and the FixedSize bits are set, an image smaller than the control is centered and an image is larger than the control it is shrunk to fit.

Remarks

This control is created as a "STATIC" with the SS_ICON, SS_CENTERIMAGE, WS_CHILD, and WS_GROUP styles.
