Microsoft Windows Installer

ExtractCAB Method

The ExtractCAB method extracts the embedded CAB file from a module and saves it as the specified file. The installer creates this file if it does not already exist and overwritten if it does exist.

Syntax

object.ExtractCAB(FileName)

Parts

object
Merge Object
FileName
The fully qualified destination file.
