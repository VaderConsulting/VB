Microsoft Windows Installer

DISABLEMEDIA Property

Setting the DISABLEMEDIA property prevents the installer from registering any media source, such as a CD-ROM, as a valid source for the product. If browsing is enabled however, a user may still browse to a media source.

Administrators can secure a managed installation with Windows Installer version 1.0 by setting both the DISABLEMEDIA property and the DisableBrowse policy. This stops users from browsing to a media source.

Note that the DISABLEMEDIA property has a different effect than setting the DisableMedia policy with Windows Installer version 1.1. Setting the DisableMedia system policy disables media sources and disables browsing to media sources. Installations using Windows Installer version 1.1 should be secured using the DisableMedia and DisableBrowse policies.
