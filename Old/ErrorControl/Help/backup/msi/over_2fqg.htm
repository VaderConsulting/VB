Microsoft Windows Installer

AllowLockdownPatch

If this per-machine system policy is set to "1", non-administrative users can apply Windows Installer patches to existing products while running an installation at elevated privileges. The default is that only administrators can patch existing products that were installed at elevated privileges. Setting this policy also enables non-admin users to run programs at LocalSystem privileges during an elevated installation.

This policy not available with Windows Installer version 1.0.

Registry Key

HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\Installer

Remarks

Any user can apply a patch during a non-elevated installation. Setting this per-machine system policy to "1" gives non-admin users the additional flexibility of applying patches to any product during an elevated installation. If this policy is not set, non-admin users cannot apply a patch to assigned or published applications.

Setting this policy also enables non-admin users to run arbitrary programs at LocalSystem privileges if they have a Windows Installer patch package that installs or launches those programs.

Note this policy is not available with Windows Installer version 1.0. Systems using version 1.0 of the installer should therefore be secured by setting DisablePatch policy. On Windows NT 4.0 using Windows Installer version 1.0, the possible security threat only applies to products that have been installed for all users of the computer.
