Microsoft Windows Installer

DirectoryListOpen ControlEvent

This event selects and highlights a directory in the DirectoryList control that the user has chosen to open.

Published By

DirectoryList

Argument

None.

Action on Subscribers

A selected folder is enabled. If no folder in selected currently, then the subscribers are disabled.

Typical Use

A PushButton control on the same modal dialog as the DirectoryList is used to trigger stepping down in the path.
