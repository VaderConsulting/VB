Microsoft Windows Installer

ApplyTransform Method

The ApplyTransform method of the Database object applies the transform to this database.

Syntax

object.ApplyTransform(storage, errorConditions)

Parts

object
Database object
storage
Required Database object containing the transform.
errorConditions
Specifies the error conditions that are to be suppressed. Specify as a combination of the following integer values.
Error condition Value Meaning
msiTransformErrorAddExistingRow 0x0001 Adding a row that already exists.
msiTransformErrorDeleteNonExistingRow 0x0002 Deleting a row that does not exist.
msiTransformErrorAddExistingTable 0x0004 Adding a table that already exists.
msiTransformErrorDeleteNonExistingTable 0x0008 Deleting a table that does not exist.
msiTransformErrorUpdateNonExistingRow 0x0010 Updating a row that does not exist.
msiTransformErrorChangeCodePage 0x0020 Transform and database code pages do not match and neither has a neutral code page.
msiTransformErrorViewTransform 0x0100 Create the temporary _TransformView table.

Remarks

The ApplyTransform method delays transforming tables until the last possible moment. The steps taken in ApplyTransform are to immediately transform the table and column catalogs for the database. The table and column catalogs are updated according to what table is added or deleted and what column is added (no deletion of columns is allowed). If a table is currently loaded in memory and needs to be transformed, it is transformed. Else, the table state is set to that requiring a transform so that when the table is loaded, or when the database is committed, the transform is applied. Transform in this instance means that the actual (row) data of the table is added, deleted, or updated.
