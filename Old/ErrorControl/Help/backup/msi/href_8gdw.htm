Microsoft Windows Installer

Reinstall ControlEvent

This ControlEvent allows the author to initiate a reinstall of some or all features, while keeping the present dialog running.

Published By

This ControlEvent is published by the installer.

Argument

A string that is either the name of the feature or "ALL".

Action on Subscribers

None.

Typical Use

A PushButton control on a modal dialog box is tied to this event and also tied to a ReinstallMode control event immediately before it.
