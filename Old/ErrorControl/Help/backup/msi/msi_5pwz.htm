Microsoft Windows Installer

MsiEnumRelatedProducts

The MsiEnumProducts function enumerates products with a specified upgrade code. This function lists the currently installed and advertised products that have the specified UpgradeCode property in their Property table.

UINT MsiEnumRelatedProducts(
  LPCTSTR lpUpgradeCode  // upgrade code of products to enumerate
  DWORD dwReserved,      // reserved, must be 0
  DWORD iProductIndex,   // 0-based index into registered products
  LPTSTR lpProductBuf    // buffer of character count 39 to receive GUID
);

Parameters

lpUpgradeCode
The upgrade code of related products that the installer is to enumerate.
dwReserved
This parameter is reserved and must be 0.
iProductIndex
The 0-based index into the registered products.
lpProductBuf
A buffer of character count 39 to receive the product code GUID.

Return Values

Value Meaning
ERROR_BAD_CONFIGURATION The configuration data is corrupt.
ERROR_INVALID_PARAMETER An invalid parameter was passed to the function.
ERROR_NO_MORE_ITEMS There are no products to return.
ERROR_SUCCESS A value was enumerated.

Remarks

See UpgradeCode property.

To enumerate currently installed and advertised products that have a specific upgrade code, an application should initially call the MsiEnumRelatedProducts function with the iProductIndex parameter set to zero. The application should then increment the iProductIndex parameter and call MsiEnumRelatedProducts until the function returns ERROR_NO_MORE_ITEMS, which means there are no more products with the specified upgrade code.

This function is not available with Windows Installer version 1.0.

Requirements

  Windows NT/2000: Requires Windows NT 4.0 SP3 or later. Available as a redistributable.
  Windows 95/98: Requires Windows 95 or later. Available as a redistributable for Windows 95.
  Header: Declared in Msi.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
