Microsoft Windows Installer

DisableMedia

If this per-user system policy is set to "1", users and administrators are prevented from using media sources for installations, such as CD-ROM, regardless of whether the installation is with elevated privileges.

This policy not available with Windows Installer version 1.0.

Registry Key

HKEY_CURRENT_USER\Software\Policies\Microsoft\Windows\Installer
