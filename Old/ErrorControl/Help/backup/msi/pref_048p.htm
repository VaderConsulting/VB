Microsoft Windows Installer

FavoritesFolder Property

The installer sets the FavoritesFolder property to the full path of the Favorites folder for the current user.

Remarks

Common values for this property are C:\Winnt\Profiles\[LogonUser]\Favorites\ (Windows NT/Windows 2000) and C:\Windows\Favorites\ (Windows 95 and Windows 98).
