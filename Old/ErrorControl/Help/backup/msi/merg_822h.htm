Microsoft Windows Installer

DatabaseKeys Property

The read-only DatabaseKeys property returns a string collection that contains the primary keys of the database row causing the error. There is one key per entry in the collection.

Syntax

object.DatabaseKeys

Parts

object
Error Object

Remarks

The client is responsible for releasing the string collection when it is no longer needed.

The collection is empty if the error is of type msmErrorLanguageUnsupported or msmErrorLanguageFailed. You can determine the type of error by calling the Type property of the Error object.
