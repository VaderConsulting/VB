Microsoft Windows Installer

Patching and Upgrades

This section describes the methods Microsoft® Windows® Installer uses for updating an application. Because an installation package contains all the information needed for an installation, as well as the files that make up the application, information can be updated within the following parts of the installation package:

  • The .msi file.
  • The files of the application.
  • The Windows Installer registration information.

If the update changes the .msi file as well as application files, without changing the product code or product version, it is termed a Small Update.

If the update changes the product version, but does not change the product code, it is termed a Minor Upgrade. The product version is stored in the ProductVersion property.

If the update changes the installation into an entirely different product the product code must change and the update is a Major Upgrade. The product code is stored in the ProductCode property.

The following table summarizes the different types of updates.

Type of update ProductCode ProductVersion Description
Small Update No change No change An update to one or two files that is too small to warrant changing the ProductVersion. The package code in the Revision Number Summary Property does change. Can be shipped as a full installation package or as a patch package.
Minor Upgrade No change Changed A small update making changes large enough to warrant changing the ProductVersion property. Can be shipped as a full installation package or as a patch package.
Major Upgrades Changed Changed A comprehensive update of the product warranting a change in the ProductCode property. Shipped as a patch package or as a full product installation package.

The package code uniquely identifies an installation package and should change whenever an update or upgrade changes the installation package. See Package and Product Codes.

When deciding whether to change the product version, you should consider if future versions of the application will need to differentiate between the updated, and non-updated versions of the current product. To ensure differentiation in the future a Minor Upgrade should be used instead of a Small Update.

A Windows Installer patch package is one means of providing users with an application update. A patch can contain an entire file or only the file bits necessary to update part of a file. This means that the user can download an upgrade patch that is much smaller than the entire product and that preserves user customizations through the upgrade. For more information about updating an application using a patch, see Patch Packages and Creating a Patch Package.
