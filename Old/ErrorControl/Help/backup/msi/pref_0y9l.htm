Microsoft Windows Installer

OLEAdvtSupport Property

The installer sets the OLEAdvtSupport property to true when the current user's system has been upgraded to work with install-on-demand through COM. Note that for the installer to register a COM class and enable installation-on-demand, the class must be listed in the Class and ProgId tables.
