Code Page Handling (Windows Installer)

The Windows Installer stores all database strings in a single shared string pool to reduce the size of the database and to improve performance. The database has a single ANSI code page for the string pool appropriate for the product's localization. For list of numeric code pages, see Localizing the Error and ActionText Tables. See also Determining an installation database's code page.

Localizing a Windows installer package may involve modifying information in database tables, exporting these tables to ANSI text archive files, and then importing the archive files into the database being localized. Authors may also add localization changes to a database using a database table editor or the Database Functions. It is important to set the code page of the database being localized prior to making any localization changes to the database. Attempting to set the code page of the database after localizing the database is not recommended because this can corrupt extended characters. For details, see Setting the code page of a database.

The recommended approach for handling code pages is to author a neutral database that only contains characters that can be translated into any code page. For more information, see Creating a database with a neutral code page.

Authors adding localization information with database archive files may use MsiDatabaseExport to export tables from a database containing localization changes to ANSI text archive files and then import these into the database being localized with MsiDatabaseImport. The code page of an exported archive file is always the same as its parent database. The code pages of an imported file and the database receiving the file must be identical, or at least one of the two code pages must be neutral. See Code Page Handling of Imported and Exported Tables.

Authors adding localization information with a text editor or the Database Functions must be careful to only pass string parameters to the Windows Installer API that use the code page of the database being localized. If a string parameter contains characters not represented by the code page of the database is passed, an error occurs when calling MsiDatabaseCommit. See Code Page Handling of Parameter Strings.

In cases where one package is used for the installation of multiple language versions of a product, the transform used to localize strings can also change the code page of the database.
