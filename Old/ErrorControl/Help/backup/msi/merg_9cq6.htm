Microsoft Windows Installer

Log Function

The function Log implements the Log method of the Merge Object. This function writes a text string to the currently open log file.

IMsmMerge::Log 

HRESULT Log(
  BSTR Message
);

Parameters

Message
The text string to display. A LPCWSTR may be used instead of a BSTR.

Return Values

Value Meaning
E_FAIL There was an error writing to the log file.
E_INVALIDARG The argument is invalid.
S_FALSE No log file is open.
S_OK The function succeeded.
