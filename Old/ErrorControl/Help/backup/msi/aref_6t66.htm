Microsoft Windows Installer

RemoveShortcuts Action

The RemoveShortcuts action manages the removal of an advertised shortcut whose feature is selected for uninstall or a non-advertised shortcut whose component is selected for uninstall. For more information, see the Shortcut Table.

Sequence Restrictions

The RemoveShortcuts action must come after the InstallFiles action and before the CreateShortcuts action.

ActionData Messages

Field Description of action data
[1] Identifier of removed shortcut
