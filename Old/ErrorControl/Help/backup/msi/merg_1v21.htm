Microsoft Windows Installer

ModuleFiles Property

ModuleFiles Property returns all the primary keys of the File table for the currently open module. The primary keys are returned as a collection of strings. The module must be opened by a call to the OpenModule method of the Merge Object before calling ModuleFiles.

Syntax

object.ModuleFiles

Parts

object
GetFiles Object

Remarks

Note that order of the files listed in the collection may not be in the same sequence as listed in the File table.

If the module has no File table, or contains no files in the particular language, ModuleFiles returns an empty collection of strings.

C++

See get_ModuleFiles Function.
