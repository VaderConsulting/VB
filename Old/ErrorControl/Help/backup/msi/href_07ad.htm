Microsoft Windows Installer

Integer Control Attribute

If this bit is set on a control, the associated property specified in the Property column of the Control table is an integer.

If this bit is not set, the property is a string value.

Valid Controls

CheckBox
ComboBox
Edit
ListBox
RadioButtonGroup

Value

Decimal Hexadecimal Constant
16 0x00000010 msidbControlAttributesInteger

Remarks

To set this attribute on a control, include the Integer bit in the Attributes column of the control's record in the Control table.

See Control Attributes and Controls.
