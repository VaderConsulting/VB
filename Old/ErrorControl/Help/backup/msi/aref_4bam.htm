Microsoft Windows Installer

CostInitialize Action

The CostInitialize action initiates the installation costing process.

Sequence Restrictions

The FileCost action is called immediately following the CostInitialize action. The CostFinalize action is then called, which finalizes all cost calculations and makes them available to the installer through the Component table.

ActionData Messages

None.

Remarks

The CostInitialize action loads the Component table and Feature table into memory.

For more information on the costing process in the installer, see File Costing.
