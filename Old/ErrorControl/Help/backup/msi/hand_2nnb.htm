Microsoft Windows Installer

Dialog Box Overview

The process of creating a dialog box in Windows Installer is similar to the process of creating a dialog box programmatically using a Microsoft Windows API dialog box template. While a Windows dialog box template is stored in a null terminated character string, Windows Installer stores the dialog box parameters in the Dialog table. The Dialog table contains an attributes column that is analogous to Window styles in the Microsoft Windows user interface API. However, the number of Dialog Style Bits in Windows Installer is a reduced and specialized set.

To physically create the dialog box using the Windows user interface API, DialogBox is called and passes a pointer to the template. In Windows Installer, the dialog box is created during execution of one of the three user interface sequence tables.

Windows Installer does not contain a default user interface which package authors can utilize for their packages. Windows Installer does contain a limited set of default Dialog boxes that display error and information messages, but these are displayed only if Windows Installer queries the dialog and user interface sequence tables and finds there are no custom dialogs available.

The Windows Installer Software Developer Kit contains a minimal database named Uisample.msi that contains populated user interface and execution sequence tables and a complete user interface. This database is easily customized and merged on to any package.

Some standard actions and internal Windows Installer error conditions return a specific set of user interface data and therefore require a dialog box with a specific set of controls to accommodate that data. Windows Installer checks two separate locations for the identifiers for these dialog boxes.

  1. Windows Installer contains a set of embedded dialog box names. The custom action queries the Dialog table for these reserved names.
  2. In each of the three user interface sequence tables, dialog names with a sequence number of -1,-2, or -3 are displayed in response to exit, user requested exit, and fatal error messages from Windows Installer.

A complete list of reserved primary key dialog box names is available in dialog boxes. Note that the primary key dialog box name is only reserved by the installer and there is no specific implementation of the dialog box within Windows Installer. Package authors must still populate all the fields in the database that specify the attributes and controls of these reserved dialog boxes.
