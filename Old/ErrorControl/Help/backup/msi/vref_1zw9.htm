Microsoft Windows Installer

Patches Property

The read-only Patches property of the Installer object returns a StringList that contains all the patches applied to the product.

Syntax

object.Patches(Product)

Parts

object
Installer object
Product
Specifies the product code.

Remarks

To enumerate the patches, an application iterates through the StringList object using a For Each construct. Because patches are not ordered, any new patch has an arbitrary index. This means that the function can return patches in any order.

This property is not available with Windows Installer version 1.0.
