Microsoft Windows Installer

get_Dependencies Function

The function get_Dependencies implements the Dependencies property of the Merge Object.

IMsmMerge::Dependencies 

HRESULT get_Dependencies(
  IMsmDependencies **Dependencies  //[out, retval] 
);

Parameters

Dependencies
Pointer to a memory location to be filled with a pointer to an IMsmDependencies interface which provides access to a collection of unsatisfied dependencies for the current database. If there is an error, the memory location pointed to by Dependencies will be set to NULL.

Return Values

Value Meaning
E_INVALIDARG The Dependencies pointer is NULL
E_FAIL There was no database open.
E_UNEXPECTED Unable to verify dependencies due to internal error.
E_OUTOFMEMORY The system ran out of memory.
S_OK The function succeeded.

Remarks

There does not need to be a module open to retrieve dependency information.

The client is responsible for releasing the interface returned by this function.
