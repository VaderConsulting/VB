Microsoft Windows Installer

ProductCode Property

The ProductCode property is a unique identifier for the particular product release, represented as a string GUID, for example "{12345678-1234-1234-1234-123456789012}". This ID must vary for different versions and languages. A product upgrade that updates a product into an entirely new product must also change the product code.

Letters used in this GUID must be uppercase.

The ProductCode is advertised as a product property, and is the primary method of specifying the product. This property is REQUIRED.
