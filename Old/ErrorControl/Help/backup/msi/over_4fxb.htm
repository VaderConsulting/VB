Microsoft Windows Installer

Logging Policy (Per Machine)

This per-machine system policy is used only if logging has not been enabled by the "/L" command line option or by MsiEnableLog. If the policy is set in this case, the installer creates a log file in the temp directory with the random name: MSI*.LOG. Specify the logging mode by setting the policy value to a string of characters. Use the same characters to specify logging mode policy as used by the "/L" command line option. Note that you cannot use "+" and "*" for the policy.

Registry Key

HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\Installer
