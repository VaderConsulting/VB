Microsoft Windows Installer

SpawnDialog ControlEvent

The SpawnDialog event notifies the installer to create a child of a modal dialog box while keeping the present dialog running.

Published By

This ControlEvent is published by the installer.

Argument

A string that is the name of the new dialog.

Action on Subscribers

None.

Typical Use

A PushButton control on a modal dialog is tied to this event in the ControlEvent table to create a child dialog, such as a "Are you sure you want to cancel" dialog.
