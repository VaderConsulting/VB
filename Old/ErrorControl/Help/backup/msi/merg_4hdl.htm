DatabaseTable Property

The read-only DatabaseTable Property returns the name of the table in the database that caused the error.

Syntax

object.DatabaseTable

Parts

object
Error Object

Remarks

The table name is the empty string unless the error is of type msmErrorTableMerge or msmErrorResequenceMerge. You can determine the type of error by calling Type property of the Error Object.

C++

See get_DatabaseTable Function.
