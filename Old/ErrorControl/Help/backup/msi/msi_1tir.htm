Microsoft Windows Installer

Displayed Error Messages

The installer only displays an error message box for the following returned error codes. For any other returned error codes the caller of the function can safely assume that the error message has been displayed to the user if the UILevel property is greater than INSTALLUILEVEL_NONE.

Error code Error
ERROR_INSTALL_SUSPEND The install was suspended.
ERROR_INSTALL_USEREXIT The user exited the install.
ERROR_INSTALL_FAILURE Install failed.
