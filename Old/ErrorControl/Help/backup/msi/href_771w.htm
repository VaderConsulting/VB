Microsoft Windows Installer

SetProgress ControlEvent

The installer uses the SetProgress event to publish install progress. A control has to subscribe to the event by naming the Action whose progress is being indicated.

Published By

This ControlEvent is published by the installer.

Argument

None.

Action on Subscribers

The subscribers are hidden when a new action starts and they become visible when new progress data arrives from the installer.

Typical Use

A ProgressBar control on a modeless dialog subscribes to this event using the Progress attribute to receive the progress information.
