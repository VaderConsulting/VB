SelectionPath ControlEvent

The SelectionTree control uses the SelectionPath event to publish the path for the highlighted item. If the item is selected to run from source, then this is the path of the source. If the item is selected to be absent, then the string is the AbsentPath string from the UIText Table.

Published By

SelectionTree

Argument

None.

Action on Subscribers

None.

Typical Use

A Text control on the same modal dialog as the SelectionTree uses this event to display the path of the highlighted item.
