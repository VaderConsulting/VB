Microsoft Windows Installer

GetShortcutTarget Method

The GetShortcutTarget method examines a shortcut and returns its product, feature name, and component if available.

Syntax

object.GetShortcutTarget(Shortcut)

Parts

object
Installer object
Shortcut
Full path and file name for the lnk file.

Remarks

This property is not available with Windows Installer version 1.0.

See Also

MsiGetFeatureState; MsiGetComponentState.
