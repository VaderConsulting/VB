Microsoft Windows Installer

MSIMSP.EXE

The recommended method for generating a patch package is to use a patch creation tool such as MsiMsp.exe and Patchwiz.dll. The tool MsiMsp.exe is provided in the Platform SDK Components for Windows Installer Developers. The source code for Patchwiz.DLL is also provided in the SDK so that you can customize and enhance the patch creation process.

The MsiMsp.exe tool is a executable that calls PatchWiz.dll. The tool may be used to create a patch package by passing in the path to a patch creation properties file (.pcp file) and the path to the patch package being created. The tool can also be used to create a log file and to specify a temporary folder in which the transforms, cabinets and files used to create the patch package are saved. The command line syntax for MsiMsp.exe is:

MsiMsp.exe -s [path to .pcp file] -p [path to .msp file] {options}

The command line options are not case-sensitive and slash delimiters may be used instead of a dash.

Option Parameter Description
-s path to .pcp file This is required and must be followed by the path to the patch creation properties file (.pcp extension). For more information about patch creation files see PatchWiz.dll.
-p path to .msp file This is required and followed by the path to patch package being created (.msp extension).
-f path to temporary folder Optional. Followed by path to temporary folder. The default location is %TEMP%\~pcw_tmp.tmp\.
-k Optional. Fail if the temporary folder already exists.
-l path to log file Optional. Followed by the path to log file describing patch creation process and errors. See Return Values for UiCreatePatchPackage.
-d Optional. Displays a dialog if the patch creation completes successfully.
-? Displays command line help.
