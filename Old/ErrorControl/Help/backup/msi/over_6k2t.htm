Microsoft Windows Installer

AllowLockdownBrowse

If this per-machine system policy is set to "1", non-admin users can browse for new sources while running an installation at elevated privileges. The default is that only administrators can browse for sources during an elevated installation. Setting this policy also enables non-admin users to run programs at LocalSystem privileges during an elevated installation.

This policy not available with Windows Installer version 1.0.

Registry Key

HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\Installer

Remarks

Any user can browse for new sources during a non-elevated installation. Setting the value of this system policy to "1" gives non-admin users the additional flexibility of browsing for new sources during an elevated installation. If this policy is not set, non-admin users cannot browse for new sources for assigned or published applications.

Setting this policy also enables non-admin users to run arbitrary programs at LocalSystem privileges if they have a Windows Installer installation package that installs or launches those programs.

Note this policy is not available with Windows Installer version 1.0. Systems using version 1.0 of the installer should therefore be secured by setting the DisableBrowse policy. On Windows NT version 4.0 using Windows Installer version 1.0, the possible security threat only applies to products that have been installed for all users of the computer.
