Microsoft Windows Installer

NewDialog ControlEvent

This event notifies the installer to transition a modal dialog box to another dialog box. The installer removes the present dialog and creates the new one with the name indicated in the argument.

Published By

This ControlEvent is published by the installer.

Argument

A string that is the name of the new dialog.

Action on Subscribers

None.

Typical Use

A PushButton control on a modal dialog is tied to this event in the ControlEvent table to signal a transition to the next or previous dialog of the same wizard sequence.
