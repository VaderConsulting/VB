Microsoft Windows Installer

CloseDatabase Method

The CloseDatabase method closes the currently open Windows Installer database.

Syntax

object.CloseDatabase(bCommit)

Parts

object
Merge Object
bCommit
TRUE if changes should be saved, FALSE otherwise.

Remarks

Closing a database clears all dependency information, but does not affect any errors that have not been retrieved.
