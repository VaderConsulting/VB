SelectionPathOn ControlEvent

The SelectionTree control uses the SelectionPathOn event to publish a Boolean value indicating whether there is a selection path associated with the currently selected feature.

Published By

SelectionTree

Argument

None.

Action on Subscribers

None.

Typical Use

A Text control on the same modal dialog as the SelectionTree uses this event for the caption of the selection path. This text control is visible or hidden depending on the event.
