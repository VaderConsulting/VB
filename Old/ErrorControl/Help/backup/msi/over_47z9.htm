Microsoft Windows Installer

EnableAdminTSRemote

Setting this per-machine system policy enables administrators to perform installations from Terminal Server client sessions. If this policy is not set, administrators can only perform installations from the console. Non-admin users can never do installs from client sessions. See Terminal Services in the Platform SDK.

Administrators can always do Administrative installations from a Terminal Server client session, or from the console, regardless of whether this policy is set.

Registry Key

HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\Installer

Remarks

Note this policy is not available with Windows Installer version 1.0.
