SelectionBrowse ControlEvent

The SelectionTree control uses the SelectionBrowse event to spawn a browse dialog making it possible to modify the path of the highlighted item.

Published By

SelectionTree

Argument

The name of the dialog to be spawned.

Action on Subscribers

Controls that subscribe to this event are disabled if the path of the currently selected item cannot be modified by the user.

Typical Use

A PushButton control on the same modal dialog as the SelectionTree uses this event to trigger the browse dialog.
