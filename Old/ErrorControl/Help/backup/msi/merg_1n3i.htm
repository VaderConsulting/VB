Microsoft Windows Installer

get_Version Function

The function get_Version implements the Version Property of the Dependency Object. This function returns the version of the required module in the form of a BSTR.

IMsmDependency::get_Version 

HRESULT get_Version(
  BSTR *Version   //[out, retval]
);

Parameters

Version
A pointer to a location in memory that is filled in with a BSTR value.

Return Values

Value Meaning
E_INVALIDARG Version is NULL.
S_OK The function succeeded.

Remarks

The client is responsible for freeing the resulting string using SysFreeString().
