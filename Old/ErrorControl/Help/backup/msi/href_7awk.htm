Microsoft Windows Installer

EnableRollback ControlEvent

This control event can be used to turn on or turn off the installer's rollback capabilities.

Published By

This ControlEvent is published by the installer.

Argument

False turns off the installer's rollback capabilities. True turns on the installer's rollback capabilities.

Action on Subscribers

None.

Typical Use

Can be used to turn off rollback capabilities if the installer detects that there is insufficient disk space available to complete the install. For this case, the ControlEvent should be used with the OutOfDiskSpace, OutOfNoRbDiskSpace, and the PROMPTROLLBACKCOST properties.
