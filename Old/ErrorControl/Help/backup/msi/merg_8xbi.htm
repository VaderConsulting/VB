get_Type Function

The function get_Type implements the Type property of the Error Object. This function returns a msmErrorType value indicating the type of error represented by this object.

IMsmError::get_Type 

HRESULT get_Type(
  msmErrorType *ErrorType   //[out, retval]
);

Parameters

ErrorType
A pointer to a location in memory that is filled with the type of error.
msmErrorType Value
msmErrorLanguageUnsupported 1
msmErrorLanguageFailed 2
msmErrorExclusion 3
msmErrorTableMerge 4
msmErrorResequenceMerge 5
msmErrorFileCreate 6
msmErrorDirCreate 7
msmErrorFeatureRequired 8

Return Values

Value Meaning
E_INVALIDARG ErrorType is Null.
S_OK The function succeeded.
