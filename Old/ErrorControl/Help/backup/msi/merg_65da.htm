Microsoft Windows Installer

get_ModuleKeys Function

The function get_ModuleKeys implements the ModuleKeys property. This function returns a pointer to a string collection containing the primary keys of the row in the module causing the error, one key per entry in the collection.

IMsmError::get_ModuleKeys 

HRESULT get_ModuleKeys(
  IMsmStrings **ErrorKeys   //[out,retval]
);

Parameters

ErrorKeys
A pointer to a location in memory that is filled with a pointer to a string collection.

Return Values

Value Meaning
E_INVALIDARG ErrorKeys is NULL.
S_OK The function succeeded

Remarks

The client is responsible for releasing the string collection when it is no longer needed.

The collection will be empty if the error is of type msmErrorLanguageUnsupported or msmErrorLanguageFailed. You can determine the type of error by calling IMsmError::Type.
