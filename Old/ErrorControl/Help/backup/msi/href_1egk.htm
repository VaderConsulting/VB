Microsoft Windows Installer

TimeRemaining ControlEvent

The installer uses the TimeRemaining event to publish the approximate time remaining, in seconds, for the current progress sequence.

Published By

This ControlEvent is published by the installer.

Argument

None.

Action on Subscribers

None.

Typical Use

A text control on a modeless dialog subscribes to this event via the EventMapping table and uses the TimeRemaining attribute to display the time remaining.

The same text control that subscribes to the TimeRemaining ControlEvent can also subscribe to the ScriptInProgress ControlEvent. In this case, as the preliminary ScriptInProgress message string, it is replaced by the "Time Remaining: xx minutes" string.
