Microsoft Windows Installer

DirectoryListUp ControlEvent

This event notifies the DirectoryList control that the user wants to select the parent of the present directory.

Published By

DirectoryList

Argument

None.

Action on Subscribers

The subscribers are disabled if the current directory is a volume and has no parent. Subscribers are otherwise enabled.

Typical Use

A PushButton control on the same modal dialog as the DirectoryList is used to trigger stepping up in the path.
