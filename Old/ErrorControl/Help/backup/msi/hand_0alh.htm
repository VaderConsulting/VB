Microsoft Windows Installer

User Interface

The Microsoft® Windows® Installer provides a complete user interface for installing an application or product. The user interface presents the user with the options available to configure the installation and obtains information from the user about the pending installation process.

About the User Interface describes the functionality of Windows Installer user interface. Using the User Interface describes the use of the Windows Installer internal user interface.

Reference information on Windows Installer internal dialog box and control styles and options is presented in User Interface Reference.
