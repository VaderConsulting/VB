Microsoft Windows Installer

AlwaysInstallElevated (Per-Machine)

If this per-machine system policy is set to "1", and AlwaysInstallElevated (Per-User) is also set, the installer always installs with elevated privileges.

Otherwise, the installer uses elevated privileges to install managed applications and uses the current user's privilege level for non-managed applications.

Registry Key

HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\Installer
