Microsoft Windows Installer

RedirectedDLLSupport Property

The installer sets the RedirectedDLLSupport property if the system platform performing the installation supports Isolated Components. The installer sets the property for Windows 98 SE and Windows 2000 and later system versions.

The RedirectedDLLSupport property may be used to condition the IsolateComponents action in the InstallUISequence table or InstallExecuteSequence table.

This property is only available in Windows Installer version 1.1 and later versions.
