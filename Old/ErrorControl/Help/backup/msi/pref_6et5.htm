Microsoft Windows Installer

ProductID Property

The ProductID property is set to the full Product ID after a successful validation. If the installer package does not use a Product ID, then the ProductID property must be set to "none" in the Property table.

This value is displayed by the UI and used by the RegisterProduct action.

Following a successful validation, this property is set by the ValidateProductID action or the ValidateProductID ControlEvent.
