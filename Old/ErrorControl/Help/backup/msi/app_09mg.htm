Microsoft Windows Installer

_MSIExecute Mutex

The _MSIExecute mutex is set only while processing the InstallExecuteSequence table, AdminExecuteSequence table or AdvtExecuteSequence table.

Because two installations cannot be run in the same process, an attempt to call the installer's application programming interface (API) returns ERROR_INSTALL_ALREADY_RUNNING in two cases:

  • While the _MSIExecute mutex is set.
  • While the current process is processing the InstallUISequence table, AdminUISequence table or AdvtUISequence table.
