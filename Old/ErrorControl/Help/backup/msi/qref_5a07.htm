Microsoft Windows Installer

MsiRecordSetString

The MsiRecordSetString function copies a string into the designated field.

UINT MsiRecordSetString(
  MSIHANDLE hRecord,     // record handle
  unsigned int iField,   // field to set
  LPCTSTR szValue        // string value
);

Parameters

hRecord
Handle to the record.
iField
Specifies the field of the record to set.
szValue
Specifies the string value of the field.

Return Values

ERROR_INVALID_HANDLE
An invalid or inactive handle was supplied.
ERROR_INVALID_PARAMETER
An invalid parameter was passed to the function.
ERROR_SUCCESS
The function succeeded.

Remarks

In the MsiRecordSetString function, a NULL string pointer and an empty string both set the field to NULL. Attempting to store a value in a non-existent field causes an error.

To set a record string field to NULL, set szValue to either a NULL string or an empty string.

Requirements

  Windows NT/2000: Requires Windows NT 4.0 SP3 or later. Available as a redistributable.
  Windows 95/98: Requires Windows 95 or later. Available as a redistributable for Windows 95.
  Header: Declared in Msiquery.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
