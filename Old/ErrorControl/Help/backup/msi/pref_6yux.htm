Microsoft Windows Installer

ServicePackLevel Property

The installer sets the ServicePackLevel property to the numerical value of the operating system service pack level, if one is installed. For example, if Windows NT Service Pack Level 3 is installed, the installer sets the value of this property to 3.

The minor revision number, if there is one, is held by the ServicePackLevelMinor property.

See also Operating System Property Values.
