Microsoft Windows Installer

Page Count Summary Property

For an installation package, the Page Count Summary property contains the minimum installer version required. For the 1.0 version of the installer, this property should be set to the integer 100.

For a transform package, the Page Count Summary property contains minimum installer version required to process the transform. Set to the greater of the two Page Count property values belonging to the databases used to generate the transform.

The Page Count Summary Property is set to Null in patch packages.

This summary property is REQUIRED.
