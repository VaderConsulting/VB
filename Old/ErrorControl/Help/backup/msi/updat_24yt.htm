Microsoft Windows Installer

Creating a Patch Package

Developers create a patch package by generating a patch creation file and using MsiMsp.exe to call UiCreatePatchPackage in Patchwiz.DLL. MsiMsp.exe and Patchwiz.dll are provided in the Windows Installer SDK. The source code for Patchwiz.dll is also provided as an example so that you can customize and enhance the patch creation process. For more information see A Small Update Patching Example.
