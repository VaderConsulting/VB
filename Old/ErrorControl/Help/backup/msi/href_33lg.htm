Microsoft Windows Installer

ActionData ControlEvent

The installer uses this event to publish data on the latest action.

Published By

This Control Event is published by the installer.

Argument

None.

Action on Subscribers

The subscribers are hidden when a new action starts and they are shown when new action data arrives from the installer.

Typical Use

A Text control on a modeless dialog subscribes to this event using the text attribute to receive the latest data on the current action. Used commonly to display the names of the files copied during file copy.
