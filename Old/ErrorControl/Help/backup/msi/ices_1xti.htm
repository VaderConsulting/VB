Microsoft Windows Installer

ICE16

ICE16 validates that the value of the ProductName property in the Property table is no greater than 63 characters in length.

The installer truncates ProductName values that are 31 to 63 characters in length to 31 characters. A longer name does not show when the registry key for DisplayName is set in the Uninstall for ARP.

Result

ICE16 posts an error message if the ProductName set in the Property table is longer than 63 characters.
