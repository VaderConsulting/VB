SelectionNoItems ControlEvent

The SelectionTree control uses the SelectionNoItems event to delete obsolete item description text or to disable buttons that have become useless.

Published By

SelectionTree control if the selection has no nodes.

Argument

None.

Action on Subscribers

Deletes obsolete item description text or disables obsolete button.

Typical Use

May be used to disable the Next, Reset and DiskCost buttons on the SelectionDialog dialog when a selection has no nodes and these buttons become useless.
