Microsoft Windows Installer

MsiGetShortcutTarget

The MsiGetShortcutTarget function examines a shortcut and returns its product, feature name, and component if available.

UINT MsiGetShortcutTarget(
  LPCDSTR szShortcutTarget,     // path to shortcut link file
  LPDSTR szProductCode,        // fixed length buffer for product code
  LPDSTR szFeatureId,          // fixed length buffer for feature id
  LPDSTR szComponentCode,      // fixed length buffer for component code
);

Parameters

szShortcutTarget
The full path to a shortcut.
szProductCode
A GUID for the product code of the shortcut, if available. Can be NULL.

Size: cchProductCode + 1.

szFeatureId
The feature name of the shortcut, if available. Can be NULL.

Size: cchMaxFeatureName + 1.

szComponentCode
A GUID of the component code, if available. Can be NULL.

Size: cchComponentId + 1.

If return buffers are provided, they must be large enough for the return values and a terminating NULL, as defined in msi.h.

Return Values

ERROR_SUCCESS
The function succeeded.
ERROR_FUNCTION_FAILED
The function failed.

Remarks

If the function fails, and the shortcut exists, the regular contents of the shortcut may be accessed through the IShellLink interface.

Otherwise, the state of the target may be determined by using the Installer Selection Functions.

Requirements

  Windows NT/2000: Requires Windows NT 4.0 SP3 or later. Available as a redistributable.
  Windows 95/98: Requires Windows 95 or later. Available as a redistributable for Windows 95.
  Header: Declared in Msiquery.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
