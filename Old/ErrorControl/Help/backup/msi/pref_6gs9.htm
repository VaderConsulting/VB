Microsoft Windows Installer

Version9X Property

The Version9X property gives the version number for the Windows 95, Windows 98, or Windows Millennium Edition operating systems.

The value of this property is an integer: MajorVersion * 100 + MinorVersion. The property remains undefined if the operating system is not Windows 95, Windows 98, or Windows Millennium Edition.

See also Operating System Property Values.

Remarks

Condition expressions can test for the version of Windows 95, Windows 98, or Windows Millennium Edition by using the property name or may verify the version by using a comparison operator.

All property names are case-sensitive. Note that the X in the name Version9X is in uppercase.
