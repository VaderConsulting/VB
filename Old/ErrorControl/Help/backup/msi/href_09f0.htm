DirectoryList Control

A DirectoryList control displays a part of the path that is currently displayed in the PathEdit control. The DirectoryList control displays the folders below the directory currently displayed by the DirectoryCombo control. If any of these folders that do not exist, they are displayed with a different icon.

The PathEdit, DirectoryCombo, and DirectoryList controls are associated with the same string valued property. That property is the path selected by the user. Enter the property's name into the Property column of the Control table. This property must have an initial value containing at least a one volume and one sublevel. Specify the initial value for the property in the Value column of the Property table.

This control is intended to be used on a Browse Dialog together with the PathEdit and DirectoryList controls.

The DirectoryList control publishes the following ControlEvents.

Control event Description
DirectoryListNew Create a new folder and select the name field for editing.
IgnoreChange Highlight, but do not open, a folder in the current directory.
DirectoryListUp Select the parent of the present directory.
DirectoryListOpen Select and highlight a directory.

The contents of the Text field of the Control table is never displayed by the DirectoryList control. Instead this field specifes the style of text to be displayed by the control and contains a description of the control used by screen review utilities. To set the font and font style of the text displayed by the control, begin the Text column of the Control table with {\style}, where style is an identifier listed in the TextStyle column of the TextStyle table. Use {&style} to apply the base font and font style. The information following this is read by screen review utilities as the description of the control. See Accessibility.

Remarks

The control is created with the WC_LISTVIEW class with the LVS_LIST, LVS_EDITLABELS, WS_VSCROLL, LVS_SHAREIMAGELISTS, LVS_AUTOARRANGE, LVS_SINGLESEL, WS_BORDER, LVS_SORTASCENDING, WS_CHILD, WS_GROUP, WS_TABSTOP styles.

This control enables the user to select a subfolder of the current selection. With additional buttons it also lets the user select a new phantom folder in current selection or step up one step in the path. If the user chooses the create new folder button in a folder where there is a phantom folder already, this folder is selected for editing instead of creating a second phantom folder.
