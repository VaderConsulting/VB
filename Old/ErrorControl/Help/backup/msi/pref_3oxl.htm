Microsoft Windows Installer

RemoteAdminTS Property

The installer sets this property when the system is configured for Remote Administration using Windows Terminal Services. Note that in this case the installer does not set the TerminalServer property.

Note that this property is not available with Windows Installer version 1.0.

Default Value

None. The property is undefined when not running on a remote administration server with Terminal Services.

Remarks

The RemoteAdminTS property can only be set on Microsoft Windows® 2000 or later. The TerminalServer property can be set on Microsoft® Windows® 2000 or Windows NT® 4.0.
