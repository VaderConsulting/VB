Microsoft Windows Installer

MsiSourceListForceResolution

The MsiSourceListForceResolution function forces the installer to search the source list for a valid product source the next time a source is needed. For example, when the installer performs an installation or reinstallation, or when it needs the path for a component that is set to run from source. 

UINT MsiSourceListForceResolution(
  LPCTSTR szProduct,     // product code
  LPCTSTR szUserName,    // user name or NULL
  DWORD dwReserved       // reserved, must be 0
);

Parameters

szProduct
Specifies the product code.
szUserName
User name for per-user installation; NULL or empty string for per-machine installation. The user name should always be in the format of DOMAIN\USERNAME (or MACHINENAME\USERNAME for a local user).
dwReserved
Reserved for future use. This value must be set to 0.

Return Values

Value Meaning
ERROR_INVALID_PARAMETER An invalid parameter was passed to the function.
ERROR_SUCCESS The function succeeded.
ERROR_UNKNOWN_PRODUCT The specified product is unknown.
ERROR_FUNCTION_FAILED The function could not complete.
ERROR_ACCESS_DENIED The caller does not have sufficient access to force resolution for the product.
ERROR_BAD_USER_NAME The specified user is not a valid user.
ERROR_INSTALL_SERVICE_FAILURE The installation service could not be accessed.
ERROR_BAD_CONFIGURATION The configuration data is corrupt.

Remarks

An administrator can force resolution for per-user non-managed installations for himself/herself, per-machine installations, and per-user managed installations for any user. Non-administrators can only force a resolution for their own installations (managed or non-managed) and per-machine installations.

If the user name is an empty string or NULL, the function operates on the per-machine install of the product. If the product is installed, but is a per-user installation, the function returns ERROR_UNKNOWN_PRODUCT.

If the user name argument is non-empty, it specifies the name of the user whose product installation will be modified. If the current user name is provided, the function first attempts to modify a non-managed install. If no product is found, the function then tries the same product but managed per-user. If the product is not found in either place, the function returns ERROR_UNKNOWN_PRODUCT, even if the product is installed per-machine.

If the user name does not belong to the current user, the function only checks the managed product for the specified user. It is not possible to modify a non-managed install for a user other than the current one. If the product is not installed in a managed per-user state for the specified user, the function returns ERROR_UNKNOWN_PRODUCT, even if the product is installed per-machine.

This function is not available with Windows Installer version 1.0.

Requirements

  Windows NT/2000: Requires Windows NT 4.0 SP3 or later. Available as a redistributable.
  Windows 95/98: Requires Windows 95 or later. Available as a redistributable for Windows 95.
  Header: Declared in Msi.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
