TrackDiskSpace Dialog Style Bit

If this bit is set, the dialog periodically calls the installer. If the property changes, it notifies the controls on the dialog. This style can be used if there is a control on the dialog indicating whether you are out of disk space. If the user switches to another application and adds or removes files or otherwise modifies the available disk space, you can quickly catch the change using this style.

Any dialog relying on the OutOfDiskSpace property to determine whether to bring up a dialog must set the TrackDiskSpace Dialog Style Bit for the dialog to dynamically update space on the target volumes.

Value

Decimal Hexadecimal Constant
32 0x00000020 msidbDialogAttributesTrackDiskSpace
