Microsoft Windows Installer

SystemFolder Property

The installer sets the SystemFolder property to the full path to the System folder.

Remarks

Common values for this property are: C:\Winnt\System32 (Windows NT/Windows 2000) and C:\Windows\System\ (Windows 95 and Windows 98).

This folder is normally a subfolder of the Windows folder. However, it will reside on a server when configured for Shared Windows.
