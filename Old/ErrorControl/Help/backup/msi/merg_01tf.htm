Authoring Merge Module File Tables

A File table is required in every merge module. The File table should have a record for each file being delivered to the target installation package by the merge module. When the merge module is merged into a .msi file, every file in the merge module File table is stored inside of a cabinet file in the .msm file. The name of this cabinet in a merge module is always: MergeModule.CABinet. For more information, see also Generating MergeModule.CABinet Cabinet Files.

  • Because the files of a merge module are always stored inside a cabinet file, it is not necessary to set the msidbFileAttributesNoncompressed or msidbFileAttributesCompressed bit flags in the Attributes column of the File table.
  • The names of files in MergeModule.CABinet must match the primary key in the merge module's File table. Note that the File column is the primary key of the File Table and that the entries in this field must follow the convention described in Naming Primary Keys in Merge Module Databases.
  • File sequence numbers are specified in the Sequence column of the File table. Files must be listed in the merge module's File table in the same sequence as they are stored in MergeModule.CABinet. The sequence numbers of files do not need to be consecutive, but they must follow the same sequence of the files stored inside the cabinet. For example, the first, second, and third files stored in the cabinet can have the sequence numbers 100, 200, and 300.
  • The installer skips extra files included in MergeModule.CABinet that are not listed in the File table. This means that a single cabinet file can contain all the files necessary for a merge module supporting multiple languages using transforms. All the language files can be given a unique sequence number in the cabinet and then a transform can add or remove files from the File table as needed for a particular language. For more information, see Authoring Multiple Language Merge Modules.

For information on how to populate the remaining fields in this table, see column descriptions in File table.
