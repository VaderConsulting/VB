SetProperty ControlEvent

The syntax for the SetProperty event is different than for other ControlEvents In place of the name of the event one puts the property in square brackets: [property_name]. The argument is the new value of the property. To unset the property, the argument must be {}. This is necessary, because the argument is a primary key in the table and so cannot be null. The argument will be formatted using the FormatText method, therefore it can contain any expression that that method can handle. The property values are evaluated at the moment of the control event.

Published By

This ControlEvent is published by the installer.

Argument

The new value of the property. {} for null.

Action on Subscribers

None.

Typical Use

A PushButton control on a dialog linked to this event so it changes a property when the button is pushed.
