Position Control Attribute

This attribute determines the position of the control on the dialog. The four fields of the attribute are: left, top, width, and height. Enter the control's width, height, and coordinates of the control's left corner into the Width, Height, X, and Y columns of the Control table. Use pixels for units of length and distance.

Valid Controls

All active controls.

Associated Bit Flags

None.

Remarks

See Control Attributes and the control you need to create under Controls.
