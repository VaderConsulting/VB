Microsoft Windows Installer

DisableRollback Policy (Per-User)

If this per-user system policy is set to "1", the installer does not store rollback files during installation and disables installation rollback. By default, rollback is enabled. Administrators are advised to not use this policy unless it is absolutely essential. For more information, see Rollback Installation.

Registry Key

HKEY_CURRENT_USER\Software\Policies\Microsoft\Windows\Installer
