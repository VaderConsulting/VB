Microsoft Windows Installer

AdminToolsFolder Property

Full path to the file system directory that stores administrative tools for a user. Microsoft® Management Console saves customized consoles to this directory and roams with the user. If the ALLUSERS property is set, this property points to the file system directory containing the administrative tools for all users of the computer.

Remarks

This property is not available with Windows Installer version 1.0.
