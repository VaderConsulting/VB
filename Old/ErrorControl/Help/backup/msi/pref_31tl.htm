Microsoft Windows Installer

RESUME Property

The RESUME property is set when resuming a suspended install. This property can determine what text to display in the UI. For example, when not in resume mode the user could be asked "Are you ready to install?" while in resume mode the user could be asked "Are you ready to complete your install?".

Remarks

For backward-compatibility, the installer also supports the name Resume for this property.
