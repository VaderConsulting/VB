Microsoft Windows Installer

Error Object

The Error object returns the information of a single merge error.

Interface ID:

Constant Value
IID_IMsmError {0ADDA828-2C26-11D2-AD65-00A0C9AF11A6}

Properties

Property Description
Type Return the type of error.
Path Return the path to the file or directory causing the error. Currently unused.
Language Return the language of the error.
DatabaseTable Returns the table name of the table in the database causing the error.
ModuleTable Returns the table name of the table in the module causing the error.
DatabaseKeys Returns the primary keys of the row in the database table that caused the error.
ModuleKeys Returns the primary keys of the row in the module table that caused the error.

Methods

None.
