Microsoft Windows Installer

MsiSourceListAddSource

The MsiSourceListAddSource function adds a source to the list of valid network sources in the source list. 

UINT MsiSourceListAddSource(
  LPCTSTR szProduct,     // product code
  LPCTSTR szUserName,    // user name or NULL
  DWORD dwReserved,      // reserved, must be 0
  LPCTSTR szSource       // pointer
);

Parameters

szProduct
Specifies the product code.
szUserName
User name for per-user installation; NULL or empty string for per-machine installation. The user name should always be in the format of DOMAIN\USERNAME (or MACHINENAME\USERNAME for a local user).
dwReserved
Reserved for future use. This value must be set to 0.
szSource
Pointer to the string specifying the source.

Return Values

Value Meaning
ERROR_INVALID_PARAMETER An invalid parameter was passed to the function.
ERROR_SUCCESS The source was added.
ERROR_UNKNOWN_PRODUCT The specified product is unknown.
ERROR_FUNCTION_FAILED The function did not succeed.
ERROR_ACCESS_DENIED The user does not have the ability to add a source.
ERROR_BAD_USERNAME Could not resolve the user name.
ERROR_INSTALL_SERVICE_FAILURE Could not access installer service
ERROR_BAD_CONFIGURATION The configuration data is corrupt.

Remarks

An administrator can modify per-user non-managed installations for himself/herself, per-machine installations, and per-user managed installations for any user. Non-administrators can only modify their own installations (managed or non-managed) and per-machine installations, and then only if they are allowed to browse for a source for the product. For more information, see DisableBrowse, AllowLockdownBrowse, AlwaysInstallElevated (per user), and AlwaysInstallElevated (per machine) policies.

Note that the newly added source is merely added to the set of valid sources. If another source in the set was used to install the product, the new source is not used until the current source is unavailable.

It is the responsibility of the caller to ensure that the provided source is a valid source image for the product.

If the user name is an empty string or NULL, the function operates on the per-machine install of the product. If the product is installed, but is a per-user install, the function returns ERROR_UNKNOWN_PRODUCT.

If the user name argument is non-empty, it specifies the name of the user whose product install will be modified. If the current user name is provided, the function first attempts to modify a non-managed install. If no product is found, the function then tries the same product but managed per-user. If the product is not found in either place, the function returns ERROR_UNKNOWN_PRODUCT, even if the product is installed per-machine.

If the user name does not belong to the current user, the function will only check the managed product for the specified user. It is not possible to modify a non-managed install for a user besides the current one. If the product is not installed in a managed per-user state for the specified user, the function will return ERROR_UNKNOWN_PRODUCT, even if the product is installed per-machine.

This function is not available with Windows Installer version 1.0.

Requirements

  Windows 95/98: Requires Windows 95 or later. Available as a redistributable for Windows 95.
  Header: Declared in Msi.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
