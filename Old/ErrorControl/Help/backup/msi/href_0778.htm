SelectionIcon ControlEvent

The SelectionTree control uses the SelectionIcon event to publish the handle to the icon for the highlighted item.

Published By

SelectionTree

Argument

None.

Action on Subscribers

None.

Typical Use

An Icon control on the same modal dialog as the SelectionTree subscribes to this event to display the icon corresponding to the highlighted item.
