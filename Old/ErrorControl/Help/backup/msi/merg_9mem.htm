Microsoft Windows Installer

CloseDatabase Function

The function CloseDatabase implements the CloseDatabase method of the Merge Object. The function closes the currently open Windows Installer database.

IMsmMerge::CloseDatabase 

HRESULT CloseDatabase(
  VARIANT_BOOL bCommit
);

Parameters

bCommit
TRUE if changes should be saved, FALSE otherwise.

Return Values

Value Meaning
E_FAIL There was an error closing the database. The state of the IMsmMerge interface is now in an undefined state.
STG_E_CANTSAVE as HRESULT Unable to save database. This error will not be generated if bCommit is FALSE.
S_FALSE No database was open.
S_OK The function succeeded.

Remarks

This function closes the currently open database. Closing a database clears all dependency information but does not affect any errors that have not been retrieved.
