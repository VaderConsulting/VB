Microsoft Windows Installer

DirectoryListNew ControlEvent

This event notifies the DirectoryList control that a new folder must be created, creates a new folder, and selects the name field of the folder for editing.

Published By

DirectoryList

Argument

None.

Action on Subscribers

None.

Typical Use

A PushButton control on the same modal dialog as the DirectoryList is used to trigger the creation of a new folder.
