ReadStream Method

The ReadStream method of the Record object reads a specified number of bytes from a record field holding stream data.

Syntax

object.ReadStream(field, length, format)

Parts

object
Record object
field
Required field number of the value within the record, 1-based.
length
Required number of bytes to read from the stream.
format
Required interpretation and return of the data bytes, one of the following:
Parameter name Value Description
msiReadStreamInteger 0 As a long integer, length must be 1 to 4.
msiReadStreamBytes 1 Data as a BSTR; one byte per character.
msiReadStreamAnsi 2 ANSI bytes translated to a Unicode BSTR.
msiReadStreamDirect 3 Byte pairs returned directly as a BSTR.

Remarks

The returned value of a non-existent field is an Empty value. If the stream has fewer bytes that the count requested, the returned string is shortened appropriately.
