How do I open a multiple-language merge module in a specific language?

When merging a module into an installation database, there are two languages of interest. The first is the language of the target installation package specified by ProductLanguage in the Property table. The second is the language of the merge module, which appears in the Language column of the ModuleSignature table.

The language of the installation package may be passed to the module by the merge tool when the package is opened for the merge. However, in some cases it may be necessary to disregard the language of the target and request that the module be opened in another language. For example, in the case of an English package installing both the English and German resources from the module.

When opening a module with a language request, the merge tool checks the requested language against the languages specified in the Language column of the ModuleSignature table. The following process is used to determine which language to use:

  1. If the language in the ModuleSignature table is equal or more general than the requested language, the module opens.
  2. If the module supports the exact language requested, that language is used.
  3. If the module supports the language group of the language requested that language group is used. For example, check 9 if 1033 was requested but not found in step 2.
  4. Check if there is a language transform that changes the module to neutral.
  5. If none of the above succeed, the module does not support the requested language and so the merge fails.
