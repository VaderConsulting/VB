SelectionAction ControlEvent

The SelectionTree control uses this event to publish a string describing the the highlighted item. The string is one of the "Sel*" strings from the UIText Table.

Published By

SelectionTree

Argument

None.

Action on Subscribers

None.

Typical Use

A Text control in the same modal dialog box as the SelectionTree uses this event to display the explanation of the selected item.
