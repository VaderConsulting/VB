Microsoft Windows Installer

M

managed application
An application is a "managed application" if system (i.e. elevated) privileges are used to install the application. An application will be managed on a system if it is a per-machine installation on Windows NT 4.0 or Windows 2000 or if the application is assigned or published using Group Policy on Windows 2000.
merge
A merge combines the information in two installation databases to form a single resultant database. See Merging Databases.
merge module
A merge module is a database merged with an installation package to deliver new components to an application. Merge modules cannot be installed alone. See Merge Modules.
Microsoft Windows Installer
Client side installer service for managing the installation of applications on 32-bit platforms. The application must be encapsulated in a package. See About Windows Installer.
.msi file
An .msi file is a COM-structured storage file containing the instructions and data required to install an application. Every package contains at least one .msi file. The .msi file contains the installer database, a summary information stream, and possibly one or more transforms and internal source files. See Windows Installer File Extensions.
.msm file
A .msm file is a merge module. See also Windows Installer File Extensions.
.msp file
A .msp file is a patch package. See Windows Installer File Extensions.
.mst file
An .mst file is a transform package. See Merges and Transforms. See Windows Installer File Extensions.
