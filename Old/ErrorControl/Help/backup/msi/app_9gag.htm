Microsoft Windows Installer

__MsiPromptForCD Mutex

The __MsiPromptForCD mutex exists whenever the installer is prompting the user to insert a CD-ROM. Autoplay programs should check that the __MsiPromptForCD mutex is not currently set before starting. Note that it is possible for a prompt for a CD-ROM to occur before either the InProgress key or the _MSIExecute mutex exist.
