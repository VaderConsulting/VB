Microsoft Windows Installer

AlwaysInstallElevated (Per-User)

If this per-user system policy is set to "1", and AlwaysInstallElevated (Per-Machine) is also set, the installer always installs with elevated privileges. Otherwise, the installer uses elevated privileges to install managed applications and uses the current user's privilege level for non-managed applications.

Registry Key

HKEY_CURRENT_USER\Software\Policies\Microsoft\Windows\Installer
