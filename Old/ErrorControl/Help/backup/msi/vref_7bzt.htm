Microsoft Windows Installer

Environment Property

The Environment property of the Installer object is a read-write property that is the string value for an environment variable or the current process.

Syntax

object.Environment(variable)

Parts

object
Installer object
variable
The name of the environment variable to be read or written. This is case-insensitive.

Remarks

Setting of an environment variable with the Environment property only affects the active session. To make persistent changes to an environment variable, use the Environment table.
