Per-User Installations

Per-user installation of an application means the application is available only for a particular user.

  • The application is installed only for a particular user.
  • Shortcuts are installed only to that users' profile.
  • Applications appear only on the Add/Remove Control Panel of users that have installed the applications.
  • On Microsoft® Windows® 2000, COM registration is written to HKCU\Software\Classes.
  • May or may not run at elevated privileges.
  • Icons and transforms are stored in %USERPROFILE%\Application Data\Microsoft\Installer\{ProductCode GUID}
  • The installer sets the following properties during a per-user installations.
