Microsoft Windows Installer

Normal Logging

The installer records errors and events in its own error log. The type of logging performed by the installer is determined by setting the logging mode. Logging is enabled and the mode can be set by three methods:

  • Use MsiEnableLog or the EnableLog Method.
  • Use the /L option with Msiexec.exe. For details, see Command Line Options.
  • Use the Logging policy. For more information, see System Policy.
