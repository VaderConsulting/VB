Microsoft Windows Installer

KeepModeless Dialog Style Bit

Normally, when this bit is not set and a dialog is created through DoAction, all other (typically modeless) dialogs are destroyed. If this bit is set, the other dialogs stay alive when this dialog is created.

Value

Decimal Hexadecimal Constant
16 0x00000010 msidbDialogAttributesKeepModeless
