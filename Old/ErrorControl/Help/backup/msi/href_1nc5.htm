Microsoft Windows Installer

PropertyName Control Attribute

This is the name of the property associated with this control. If the Indirect bit is not set, the control displays or changes the value of the property having this name. This attribute is specified in the Property column of the Control table.

This attribute returns Null for inert controls.

Valid Controls

All controls.

Associated Bit Flags

None.

Remarks

See Control Attributes and the control you need to create under Controls.
