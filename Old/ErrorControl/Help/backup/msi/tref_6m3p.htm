Microsoft Windows Installer

EventMapping Table

The EventMapping table lists the controls that subscribe to some event and lists the attribute to be changed when the event is published.

The EventMapping table has the following columns.

Column Type Key Nullable
Dialog_ Identifier Y N
Control_ Identifier Y N
Event Identifier Y N
Attribute Identifier N

Columns

Dialog_
An external key to the first column of the Dialog table. Combined this field with the Control_ field identifies a control.
Control_
An external key to the second column of the Control table. Combined this field with the Dialog_ field, identifies a control.
Event
This field is identifier that specifying the type of the event subscribed to by the control. See ControlEvent Overview.
Attribute
The name of the control attribute that is set when the event in the Event column is received. The argument of the event is passed as the argument of the Attribute call to change this attribute of the control. If this column is left blank, then no attribute of the control is changed by the event. In this case, the control that published the event can still enable, disable, hide, or unhide the control.

Remarks

More than one control on a dialog box can subscribe to the same event.
