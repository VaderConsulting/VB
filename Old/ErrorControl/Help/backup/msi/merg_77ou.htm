Microsoft Windows Installer

OpenDatabase Function

The function OpenDatabase implements the OpenDatabase Method of the Merge Object. This function opens a Windows Installer installation database, located at a specified path, that is to be merged with a module.

IMsmMerge::OpenDatabase 

HRESULT OpenDatabase(
  const BSTR Path
);

Parameters

Path
Path to the database being opened.

Return Values

Value Meaning
E_FAIL There was an error opening the database.
S_OK The function succeeded.
