Transforms

Transforms alter the installation database and can be used to encapsulate the various customizations of a base package required by different groups of users. For example, in organizations where the finance and staff support departments require different installations of a product, the product's base package can be made available to everyone at one administrative installation point with the appropriate customizations distributed to each group of users separately as transforms. Administrators can also apply multiple transforms on-the-fly during an installation to efficiently assign the most appropriate installation to different users.
