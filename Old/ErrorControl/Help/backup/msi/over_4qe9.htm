Microsoft Windows Installer

AllowLockdownMedia

If this per-machine system policy is set to "1", non-admin users can use media sources, such as a CD-ROM, while running an installation at elevated privileges. The default is that only administrators can use media sources during an elevated installation. Setting this policy also enables non-admin users to run programs at LocalSystem privileges during an elevated installation. This policy not available with Windows Installer version 1.0.

Registry Key

HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\Installer

Remarks

Any user can use media sources during a non-elevated installation. Setting this policy to "1" gives non-administrative users the additional flexibility of using media sources during an elevated installation. If this policy is not set, non-admin users cannot use media sources with assigned or published applications or with applications installed for all users.

Setting this policy also enables non-admin users to run arbitrary programs at LocalSystem privileges if they have a Windows Installer package that installs or launches those programs. Note this policy is not available with Windows Installer version 1.0. Systems using version 1.0 of the installer should be secured by setting the DISABLEMEDIA property. For Windows NT version 4.0 using Windows Installer version 1.0, the possible security threat only applies to products that have been installed for all users of the computer.
