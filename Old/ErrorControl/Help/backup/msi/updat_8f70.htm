Microsoft Windows Installer

PATCHWIZ.DLL

The recommended method for generating a patch package is to use a patch creation tool such as MsiMsp.exe and Patchwiz.dll. The tool MsiMsp.exe is provided in the Platform SDK Components for Windows Installer Developers. The source code for Patchwiz.DLL is also provided in the SDK so that you can customize and enhance the patch creation process.

The PatchWiz.dll has one API, UiCreatePatchPackage (PATCHWIZ.DLL), that takes a patch creation properties file (.pcp file) and generates a Windows Installer patch package.

The .pcp file is a binary database file with the same format as a Windows Installer database (an .msi file) but with a different database schema. Therefore a .pcp file can be authored using the same tools as used for a Windows installer database. Authors may create a .pcp file by using a table editor such Orca to enter their information into the blank .pcp database provided with the SDK, template.pcp. An example of the procedure is discussed in the section A Small Update Patching Example.

The following database tables are required in every .pcp file.

  • Properties Table (PATCHWIZ.DLL)
  • ImageFamilies Table (PATCHWIZ.DLL)
  • UpgradedImages Table (PATCHWIZ.DLL)
  • TargetImages Table (PATCHWIZ.DLL)

The following are optional tables.

  • UpgradedFiles_OptionalData Table (PATCHWIZ.DLL)
  • FamilyFileRanges Table (PATCHWIZ.DLL)
  • TargetFiles_OptionalData Table (PATCHWIZ.DLL)
  • ExternalFiles Table (PATCHWIZ.DLL)
  • UpgradedFilesToIgnore Table (PATCHWIZ.DLL)
