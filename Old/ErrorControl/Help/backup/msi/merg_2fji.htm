CloseLog Function

The function CloseLog implements the CloseLog method of the Merge Object. This function closes the current log.

IMsmMerge::CloseLog 

HRESULT CloseLog();

Parameters

This function has no parameters.

Return Values

Value Meaning
E_FAIL There was an error closing the log file.
S_FALSE No log file was open.
S_OK The function succeeded.
