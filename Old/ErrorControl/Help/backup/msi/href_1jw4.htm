Microsoft Windows Installer

AddLocal ControlEvent

The this event notifies the installer, while keeping the present dialog running, that a feature or all features are to be run locally.

Published By

This ControlEvent is published by the installer.

Argument

A string, either the name of the feature or "ALL".

Action on Subscribers

None.

Typical Use

A PushButton control on a modal dialog is tied to this event and used to notify the installer without stopping the dialog.
