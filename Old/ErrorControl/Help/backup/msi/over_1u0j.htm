Code Page Handling of Imported and Exported Tables

Authors may add localization information to an installation database by importing and exporting ASCII text archive files using MsiDatabaseExport and MsiDatabaseImport. Because the database string pool uses an ANSI code page, both the database and exported text archive files have code pages. When a text archive file is exported from a database, the code page of the archive file is the same as the parent database. See Localizing the Error and ActionText Tables for a list of numeric code pages.

The ASCII text archive files exported by MsiDatabaseExport have the following format. Note that exporting a table to a text archive file translates the control characters to avoid conflicts with file delimiters. The names of the table columns are written on the first line. The column formats are written on the second line. If the table contains only ASCII data, the third line of the text file is the table's name followed by a list of the primary keys. If the table contains non-ASCII data and the database is stamped with a numeric code page, the code page number appears at the beginning of the third line. If the database contains non-ASCII data but the database is not stamped with the numeric code page, the current system's code page number is written at the beginning of the third line. The remaining lines of the text file are the data in the specified code page. If a table contains streams, MsiDatabaseExport exports each stream in the table to a separate file.

Localization is greatly facilitated by starting with a database having a neutral code page. A blank database has a neutral code page. A database containing no extended characters that require a code page to be represented in ASCII has a neutral code page. See Creating a database with a neutral code page. If a text archive file with a non-neutral code page is imported into a database that has a different non-neutral code page, the installer returns an error when calling MsiDatabaseImport. A text archive file that has a neutral code page can be imported into a database having any code page. A text archive file having any code page can be imported into a database having a neutral code page. Importing a text archive file into a database with a neutral code page sets the code page of the database to the archive file's code page. All archive files subsequently imported into the database must then have the same code page as the first file. See Determining an installation database's code page and Setting the code page of a database.

The text archive files exported by MsiDatabaseExport are intended for use with version control systems, use the Database Functions or a database table editor for editing the database.

Authors may also add localization information to an installation database using a database table editor or the Windows Installer API. See Code Page Handling of Parameter Strings.
