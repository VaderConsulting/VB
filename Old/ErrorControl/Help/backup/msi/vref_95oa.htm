Microsoft Windows Installer

SourcePath Property

The SourcePath property of the Session object is a read-only property that provides the full path to the designated folder on the source media or server image.

Syntax

object.SourcePath(folder)

Parts

object
Session object
folder
Required case-sensitive name of a folder property as specified by a primary key of the Directory table. An error is generated if the folder does not exist.
