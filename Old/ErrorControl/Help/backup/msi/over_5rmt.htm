Microsoft Windows Installer

DisableBrowse

If this per-machine system policy is set to "1", users are prevented from browsing to locate installer sources. The "Use feature from:" combo box for direct input is locked and the "Browse..." button is disabled. For more details on source browsing, see source resiliency.

DisableBrowse does not allow browsing even if AllowLockdownBrowse is set. DisableBrowse overrides AllowLockdownBrowse.

Registry Key

HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\Installer
