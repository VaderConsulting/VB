Platform SDK: Windows Installer

MsiIsProductElevated

The MsiIsProductElevated function checks whether the product is installed with elevated privileges. An application is called a "managed application" if elevated (system) privileges are used to install the application.

Note that MsiIsProductElvated does not take into account policies such as AlwaysInstallElevated, but verifies that the local system owns the product's registry data. 

UINT MsiIsProductElevated(
  LPCTSTR szProductCode,  // product code to check
  BOOL *pfElevated        // pointer to BOOL for result
);

Parameters

szProductCode
[in] The full product code GUID of the product. This parameter is required and may not be NULL or empty.
pfElevated
[out] A pointer to a BOOL for the result. This may not be NULL.

Return Values

If the function succeeds, the return value is ERROR_SUCCESS, and pfElevated is set to TRUE if the product is a managed application.

If the function fails, the return value is one of the following error codes:

Value Meaning
ERROR_UNKNOWN_PRODUCT The product is not currently known on this machine.
ERROR_INVALID_PARAMETER An invalid argument was passed to the function.
ERROR_BAD_CONFIGURATION The configuration information for the product is invalid.
ERROR_FUNCTION_FAILED The function failed.
ERROR_CALL_NOT_IMPLEMENTED This function is not available for this platform. It is only available on Windows 2000 and Windows XP.

Remarks

Available with Windows Installer version 2.0 and later. This function always fails on Windows 95, Windows 98, and Windows Me.

For more information see also How do I install a package with elevated privileges as a non-admin?.

Requirements

  Windows NT/2000/XP: Included in Windows XP and Windows .NET Server.
  Redistributable: Requires Windows Installer 2.0 on Windows NT 4.0 SP6; Windows 2000; and Windows Me.
  Header: Declared in Msi.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
