ScrollableText Control

The individual buttons are created with the "BUTTON" class.

It has the BS_RADIOBUTTON, WS_CHILD, WS_GROUP, WS_TABSTOP, WS_EX_CONTROLPARENT and BS_MULTILINE styles.

This control displays a long string of text that cannot fit entirely on the page. A common application for this control is displaying the license agreement.

Note that the string of text used with this control cannot contain an embedded property. To display text with embedded properties use instead the Text Control.

Control Attributes

You can use the following attributes with this control. To change the value of an attribute using an event, subscribe the control to a ControlEvent in the EventMapping table and list the attribute's identifier in the Attribute column. Enter the Identifier of the ControlEvent in the Event column.

Position Position of control in the dialog box.

Remarks

The control is created using the "RICHEDIT" class with the ES_MULTILINE, WS_VSCROLL, ES_READONLY, WS_TABSTOP, ES_AUTOVSCROLL, WS_CHILD, WS_GROUP, and ES_NOOLEDRAGDROP styles.
