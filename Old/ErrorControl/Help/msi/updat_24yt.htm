Platform SDK: Windows Installer

Creating a Patch Package

Developers create a patch package by generating a patch creation file and using Msimsp.exe to call UiCreatePatchPackage in Patchwiz.dll. Msimsp.exe and Patchwiz.dll are provided in the Windows Installer SDK. For more information see A Small Update Patching Example.

Because the application of a patch to a Windows Installer package results in the installation of the original sources using a new .msi file, the new .msi file must remain compatible with the layout of the original source. This means that when authoring a patch package you must adhere to the following restrictions.

  • Requires an uncompressed setup image to create a patch. For example, an administrative image or an uncompressed setup image from a CD-ROM.
  • Do not change the primary keys in the File Table between the original and new .msi file versions.
  • Do not move files from one folder to another.
  • Do not move files from one cabinet to another.
  • Do not change the order of files in a cabinet.
