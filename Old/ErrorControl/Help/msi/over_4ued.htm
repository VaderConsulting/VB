Platform SDK: Windows Installer

How do I prevent confidential information from being written into the log file?

On Windows Installer version 2.0 and later, you can prevent confidential information, such as passwords, from being entered into the log file and made visible as follows:

  • You can prevent the installer from writing the property associated with an Edit control into the log by setting the Password Control Attribute.
  • You can prevent the installer from writing a property into the log by including the property in the MsiHiddenProperties property.
  • The installer will not write information entered on a command line into the log unless the Debug system policy is set. To write command lines to the log, set the Debug system policy to a value of 7. This will not display properties included in the MsiHiddenProperties property or associated with an Edit control having the Password Control Attribute.
  • The installer never writes the information in the Password column of the ServiceInstall table into the log.
  • You can prevent the information in the Target column of the CustomAction table from being written into the log by including the HideTarget bit flag in the Type field of the CustomAction table. The value of this flag is 8192 (0x2000). For more information see Custom Action Hidden Target Option.
