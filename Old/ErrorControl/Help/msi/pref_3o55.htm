Platform SDK: Windows Installer

AdminProperties Property

The AdminProperties property is a semicolon delimited list of properties set at the time of an administrative installation. When users subsequently install from the administrative image, their installation uses the values of properties listed in AdminProperties, rather than the values in the .msi file.

Remarks

The property names in the list can be a mix of upper and lower case letters (private properties) or all upper case (public properties).

This property must never end with a semicolon.
