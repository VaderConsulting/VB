Platform SDK: Windows Installer

Platform SDK Components for Windows Installer Developers

The components of the Microsoft® Windows® Installer Software Development Kit are included in the Microsoft Platform SDK. The Microsoft Platform SDK can be downloaded from http://www.microsoft.com/msdownload/platformsdk/sdkupdate/. This site allows download of individual components of the Platform SDK.

You can obtain the latest Windows Installer redistributable from the Platform SDK Redistributables site at http://www.microsoft.com/msdownload/platformsdk/sdkupdate/psdkredist.htm.

These sites include redistributable components, documentation, installer database validation tool, database table editor, database schema, development tools, VBScript tools, sample product, and code samples.

Platform SDK Release: August 2001
