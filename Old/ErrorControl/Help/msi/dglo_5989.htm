Platform SDK: Windows Installer

T

transform
A transform is a template of the differences between two installer databases that can be applied to produce similar changes in other databases. For example, a localization transform can be used to change the language of an application. For more information, see Merges and Transforms.
transform error condition flags
A set of properties used to flag the error conditions of a transform. See MsiCreateTransformSummaryInfo.
transform validation flags
A set of properties used to verify that the transform can be applied to the database. For a list of these properties, see MsiCreateTransformSummaryInfo.
