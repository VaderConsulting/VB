Platform SDK: Windows Installer

S

sequence tables
Tables in the installer database that list actions in a sequence and specify the flow of the installation. For more information, see Using a Sequence Table.
source list
Specifies the locations where the installer is to search for external source files.
standard action
A built-in action of the Windows Installer. For more information, see Standard Actions.
SQL
Acronym for Structured Query Language.
Structured Query Language
Structured Query Language (SQL) is a language used to interrogate and process data in a relational database. You can use SQL to make queries to the installer database. See Working with Queries.
summary information stream
A storage location in the .msi file for information that can be viewed with Microsoft® Windows® Explorer. For more information about summary information, see About the Summary Information Stream.
synchronous execution
Synchronous execution of a custom action means that the installer waits for the separate thread of a custom action to complete before continuing the thread of the current installation. See Synchronous and Asynchronous Custom Actions
system policy
System administrators can use system policies to control user and computer configurations from a single location on a network. System policies propagate registry settings to a large number of machine without requiring the administrator to have detailed knowledge of the registry The system policy of the installer can be configured using the Group Policy Editor (GPE), included in Windows NT®/Windows® 2000. For more information see System Policy.
