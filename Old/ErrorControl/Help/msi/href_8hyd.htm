Progress Control Attribute

This attribute measures how far the progress indicator bar is filled up. The record contains two integers and a string. The first number is the progress, the second number is the range (the maximal possible number for the progress).

On setting, the integers can be entered as integer fields or strings containing the integers.

If the second number is missing it is assumed to be the default (1024). If the progress is larger than the range then it is changed to be the range. The third field is a string, the name of the action whose progress is displayed.

For related information, see Authoring a Progress Bar Control, and Adding Custom Actions to the ProgressBar.

Valid Controls

ProgressBar

Associated Bit Flags

None.
