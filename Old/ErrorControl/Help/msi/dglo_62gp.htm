Platform SDK: Windows Installer

R

reduced UI
A level of the installer's internal user interface capabilities. Displays only authored modeless dialog boxes. For more information, see User Interface Levels.
reinstall
A partial or complete reinstallation of an installed application. Commonly done to repair an application if any files or registry entries have become corrupted or are missing. See Reinstalling a Feature or Application.
resiliency
The capability of an application to recover gracefully from errors without presenting the user with error messages. For more information about how the installer service improves resiliency, see Resiliency.
rollback
The automatic restoration of the original state of the computer should the installation be unsuccessful. See Rollback Installation (Windows Installer).
