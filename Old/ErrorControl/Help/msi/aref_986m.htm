Platform SDK: Windows Installer

INSTALL Action

The INSTALL action is a top-level action called to install or remove components. This action queries the InstallUISequence Table and InstallExecuteSequence Table for the action to execute, the condition for action execution, and the place of the action in the sequence:

Sequence Restrictions

None.

ActionData Messages

None.

Remarks

The INSTALL action is not called from within the action table sequence, it is passed to Windows Installer when MsiInstallProduct is called, or the command line executable Msiexec.exe is called with the '/i' command line switch, or when any Windows Installer function is called that may perform an installation task, such as MsiConfigureFeature, MsiProvideComponent, or MsiInstallMissingFile.
