ImageHandle Control Attribute

The installer uses the ImageHandle control attribute to determine whether the Text control attribute is an image specified in the Binary table or the handle to an image loaded in memory at run-time. See the links of the particular controls listed in the following as Valid Controls.

The Text Control Attribute and ImageHandle Control Attribute must be used together in the Icon and Bitmap controls. For information on how to use this attribute in those controls, see Icon Control and Bitmap Control.

A typical use of the control is to display all the running applications. This is commonly done with an action that finds all the running applications and puts their names and icons into the ListView Table

The handle to the image, in string format, must be specified in the Text column of the Control table. Because the value of the handle cannot be authored into the table, it must be set by an action performed prior to creating the control.

Even if this bit is set, the other style bits governing the size and stretching of the image are still observed. For example, if an action puts a handle of an image in the table, but other style bits describe a different size, the image is shrunk or stretched to size specified by the bits.
