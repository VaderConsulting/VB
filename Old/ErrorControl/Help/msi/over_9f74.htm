Source Resiliency Policy - Windows Installer Version 1.0

The installer begins searching for a source by checking the most recently used source location in the source list, then the list of network sources, then media sources, and finally URL sources. For details, see Source Resiliency. If these searches fail, the installer may present a Browse Dialog box so that the user can search for the source manually. The browse dialog box cannot be displayed if the user interface levels is set to None. An administrator can control the display of the browse dialog to users by setting system policy.

Because Windows Installer version 1.0 includes removable media drives on all source lists, administrators using Windows Installer version 1.0 should secure managed applications by setting the DISABLEMEDIA property, the DisableBrowse policy, and by omitting the "m" option from the SearchOrder policy. This prevents non-administrators from using the browse dialog to search for sources located on media, such as a CD-ROM, and also prevents non-administrators from using these sources to install managed applications. Note that setting the DISABLEMEDIA property prevents the installer from registering any sources located on media. This prevents first time installation from sources located on media.
