Major Upgrades by Reinstalling the Product

A major upgrade can be applied to an application by completely or partially reinstalling the application.

To propagate a Major Upgrade to current users (Complete Reinstall)

  1. This method launches a complete reinstallation of the application from the command line.
  2. From the command line use either: msiexec /fvomus [path to updated .msi file] or msiexec /I [path to updated msi file] REINSTALL=ALL REINSTALLMODE=vomus.
  3. The updated .msi file is cached on the user's computer. Note that it is not possible for the user to reinstall the product using Add/Remove Programs because the updated .msi file is not yet on the user's computer.

To propagate a Major Upgrade to current users (Complete Reinstall)

  1. This method launches a complete reinstallation of the application from a program.
  2. From a program, call MsiReinstallProduct and specify REINSTALLMODE_PACKAGE, REINSTALLMODE_FILEOLDERVERSION, REINSTALLMODE_MACHINEDATA, REINSTALLMODE_USERDATA, and REINSTALLMODE_SHORTCUT
  3. The updated .msi file is cached on the users computer.

To propagate a Major Upgrade to current users (Partial Reinstall)

  1. This method launches a reinstallation of only those features or components that are affected by the major upgrade.
  2. Obtain a list of the names of features and components that are affected by the small update.
  3. From the command prompt use: msiexec /I [path to updated .msi file] REINSTALL=[Feature list] REINSTALLMODE=vomus .
  4. The updated .msi file is cached on the users computer.
