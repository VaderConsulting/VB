PrimaryKeys Property

The PrimaryKeys property of the Database object returns an Record object containing the table name in field 0 and the column names (comprising the primary keys) in succeeding fields corresponding to their column numbers. The field count of the record is the count of primary key columns.

object.PrimaryKeys(table)

Parts

object
Database object
table
Required name of an existing table. An error is generated if the table does not exist.

Remarks

The PrimaryKeys property cannot be used with the _Tables table or the _Columns table.
