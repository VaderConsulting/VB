Platform SDK: Windows Installer

D

database function
A function that accesses the installer database. These functions are provided primarily for use by installer package authoring tools and they are not intended to be used to call installer services. For more information see the chapter Database Functions. For more information about functions used to call installer services see the Installer Function Reference.
database handle
Before working with a database you must first obtain a handle to it. See Obtaining a Database Handle.
