Platform SDK: Windows Installer

ICE49

ICE49 checks for default registry entries that are not a REG_SZ type.

Result

ICE49 posts an error if there is a default registry entry that is not a REG_SZ type.

Example

ICE49 reports the following warning for the example shown. 

Reg Entry 'Reg1' is not of type REG_SZ. Default types must be REG_SZ 
    on Win95 Systems. Make sure the component is conditionalized 
    to never be installed on Win95 machines.

The value '#123' is a DWORD registry value. On Microsoft® Windows® 95 computers, default registry entries (those with no name) can only be REG_SZ values. On Microsoft® Windows® 98 and Microsoft® Windows® NT/Windows® 2000 systems, default values can be of any type. Components with non-REG_SZ default values are valid, as long as they are never installed on a Win95 computer. If they are, an error is generated at install time.

Registry Table (partial)

Registry Name Value
Reg1 #123

To fix this error, make installation of the component conditional upon the target not being a Windows 95 computer, or change the value to type REG_SZ.

You can use the following properties to author a conditional statement VersionNT, Version9X, and WindowsBuild. For example, a possible condition is: "VersionNT OR (Version9x AND WindowsBuild>=1998).
