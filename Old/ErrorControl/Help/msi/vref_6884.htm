Platform SDK: Windows Installer

LastErrorRecord Method

The LastErrorRecord method of the Installer object returns a Record object containing error parameters for the most recent error from the function that produced the error record.

object.LastErrorRecord

Parts

object
Installer object

Remarks

Only the following designated functions generate an error record. The Record object is reset after the execution of this function of any function that generates an error record.
