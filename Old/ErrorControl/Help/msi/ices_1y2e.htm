Platform SDK: Windows Installer

ICE66

ICE66 uses the tables in the database to determine which schema your database should use.

Some functionality may only be available if the package is installed on a system with Windows Installer version 1.1 or later.

Result

ICE66 posts a warning if your database is using the wrong schema.

Example

ICE66 reports the following warning for the example shown.

WARNING: Complete functionality of the IsolatedComponents table is only available with Windows Installer versions 1.1 or greater. Your schema is 100.

The IsolatedComponent Table was added in version 1.1 of the installer. In order for you to have the additional functionality resulting from use of the IsolatedComponent table, the package must be installed on a system with Windows Installer version 1.1 or greater.

This warning can be ignored if you want your package to work on Windows Installer version 1.0 and have the additional functionality of the IsolatedComponents table if your package is installed on Windows Installer version 1.1 or greater. If you are not using the IsolatedComponents table, drop it from your database. If you want your package to be installable only on version 1.1 or later, change your package schema (PID_PAGECOUNT) to 110.
