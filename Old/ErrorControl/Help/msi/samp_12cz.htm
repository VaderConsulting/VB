Platform SDK: Windows Installer

Configuring the Setup.exe Resources

Starting with Windows Installer version 2.0, a configurable bootstrap executable (Setup.exe) and configuration tool (Msistuff.exe) is included in the Platform SDK Components for Windows Installer Developers. By using Msistuff.exe to configure the resources in Setup.exe, developers can easily create a Web installation of a Windows Installer package. For more information see Internet Download Bootstrapping.

Entering the following command line configures the resources for the sample described in A URL Based Windows Installer Installation Example.

MsiStuff setup.exe /u http://www.example.com/Products/MySetup /d 
MySetup.msi /n MySetup /v 150 /i http://www.example.com/Products/Common/InstMsi /a Ansi/Instmsi.exe  
/w Unicode/Instmsi.exe
