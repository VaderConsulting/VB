Platform SDK: Windows Installer

Uninstall Registry Key

The following installer properties give the values written under the registry key:

HKEY_LOCAL_MACHINE\Software\Microsoft\Windows\CurrentVersion\Uninstall

Value Windows installer property
INSTALLPROPERTY_INSTALLEDPRODUCTNAME ProductName Property
INSTALLPROPERTY_VERSIONSTRING Derived from ProductVersion Property
INSTALLPROPERTY_HELPLINK ARPHELPLINK Property
INSTALLPROPERTY_HELPTELEPHONE ARPHELPTELEPHONE Property
INSTALLPROPERTY_INSTALLLOCATION ARPINSTALLLOCATION Property
INSTALLPROPERTY_INSTALLSOURCE SourceDir Property
INSTALLPROPERTY_INSTALLDATE Dynamically determined installation date.
INSTALLPROPERTY_PUBLISHER Manufacturer Property
INSTALLPROPERTY_LOCALPACKAGE Dynamically determined name of the cached package.
INSTALLPROPERTY_URLINFOABOUT ARPURLINFOABOUT Property
INSTALLPROPERTY_URLUPDATEINFO ARPURLUPDATEINFO Property
INSTALLPROPERTY_VERSIONMINOR Derived from ProductVersion Property
INSTALLPROPERTY_VERSIONMAJOR Derived from ProductVersion Property
INSTALLPROPERTY_PACKAGECODE Revision Number Summary Property in the Summary Information Stream.
INSTALLPROPERTY_VERSION Derived from ProductVersion Property

The ARPCOMMENTS property, ARPCONTACT property, ARPPRODUCTICON property, and ARPREADME property provide the Add or Remove Programs in Control Panel Comments, Contact, and ReadMe written under the Uninstall Registry Key.
