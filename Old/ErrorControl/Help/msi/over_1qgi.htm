Platform SDK: Windows Installer

Installing from a Terminal Server

Developers should keep the following in mind when installing from a Terminal Server:

  • Administrators and non-administrators can perform Windows Installer installations from Terminal Services console sessions.
  • Non-administrators cannot perform Windows Installer installations from Terminal Services remote sessions. Non-administrators can only install from a console session.
  • Administrators can perform Windows Installer installations from a remote session only if the EnableAdminTSRemote system policy has been set. This policy is only available with Windows Installer version 1.1 or later and Windows 2000 and later.
  • Because the Windows Installer runs as a system service, when an administrator installs from a remote session on Windows 2000, the installation must use a UNC path and not a mapped drive letter. In this case, drive letters mapped in a remote session may not be visible to the Windows Installer service. This restriction does not exist for a remote sessions run on Windows XP or later.
  • See Per-User Installations from a Terminal Server.
  • For more information about Terminal Services, see Terminal Services in the Platform SDK.
