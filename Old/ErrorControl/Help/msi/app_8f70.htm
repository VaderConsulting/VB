Platform SDK: Windows Installer

Patchwiz.dll

The recommended method for generating a patch package is to use a patch creation tool such as Msimsp.exe and Patchwiz.dll. The tool Msimsp.exe is provided in the Platform SDK Components for Windows Installer Developers.

The PatchWiz.dll has one function, UiCreatePatchPackage (Patchwiz.dll), that takes a patch creation properties file (.pcp file) and generates an installer patch package.

The .pcp file is a binary database file with the same format as a Windows Installer database (an .msi file) but with a different database schema. Therefore a .pcp file can be authored using the same tools used for an installer database. Authors may create a .pcp file by using a table editor such Orca to enter their information into the blank .pcp database provided with the Windows Installer SDK, Template.pcp. An example of the procedure is discussed in the section A Small Update Patching Example.

The following database tables are required in every .pcp file:

  • Properties Table (Patchwiz.dll)
  • ImageFamilies Table (Patchwiz.dll)
  • UpgradedImages Table (Patchwiz.dll)
  • TargetImages Table (Patchwiz.dll)

The following are optional tables:

  • UpgradedFiles_OptionalData Table (Patchwiz.dll)
  • FamilyFileRanges Table (Patchwiz.dll)
  • TargetFiles_OptionalData Table (Patchwiz.dll)
  • ExternalFiles Table (Patchwiz.dll)
  • UpgradedFilesToIgnore Table (Patchwiz.dll)

When using Patchwiz.dll version 2.0 or later, you can increase the speed of subsequent patch creation by using Patch Information Caching (Patchwiz.dll).
