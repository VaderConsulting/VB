Platform SDK: Windows Installer

EnableLog Method

The EnableLog method of the Installer object enables logging of the selected message type for all subsequent install sessions in the current process space.

object.EnableLog(logMode, logFile)

Parts

object
Installer object
logMode
Required string containing letters representing the message types to log.
logFile
Required string containing the path to the log file to be created.

Remarks

Log message types Value Description
msiMessageTypeInfo i Information-only messages
msiMessageTypeWarning w Warning messages; not fatal
msiMessageTypeError e Error messages; may be fatal
msiMessageTypeFilesInUse f List of files in use that need to be replaced
msiMessageTypeActionStart a Start of action notification
msiMessageTypeActionData r Action data record; contents action-specific
msiMessageTypeUser u User request messages
msiMessageTypeCommonData c UI initialization parameters
msiMessageTypeOutOfMemory m Out-of-memory message
msiMessageTypeVerbose v Sends large amounts of information to log file not generally useful to users. May be used for support.
msiMessageTypePropertyDump p Dump property table; "property = value" at engine termination
(Any Message Type)+ (values)+ Messages overwrite existing log files by default. Include a plus sign to append a message to an existing log file.
