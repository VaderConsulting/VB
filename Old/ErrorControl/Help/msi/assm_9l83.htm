Platform SDK: Windows Installer

About Assemblies

Microsoft® Windows® Installer has the following features which are related to common language runtime assemblies and Win32 assemblies. Authors of Windows Installer packages can utilize these features by populating the MsiAssembly table and MsiAssemblyName table.

  • Installation, repair, or removal of common language runtime assemblies and Win32 assemblies in the global assembly cache.
  • Installation, repair, or removal of common language runtime assemblies and Win32 assemblies in private locations designated for particular applications.
  • Roll back of unsuccessful installations, repairs, or removals of common language runtime assemblies.
  • Install-on-demand of common language runtime assemblies that are advertised by a strong name in the global assembly cache.
  • Install-on-demand of common language runtime assemblies and Win32 assemblies in private locations designated for particular applications.
  • Patching of common language runtime assemblies and Win32 assemblies.
  • Advertisement of shortcuts that point to common language runtime assemblies and Win32 assemblies.

For more information, see Using Assemblies.
