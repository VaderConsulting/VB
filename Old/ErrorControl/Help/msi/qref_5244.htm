MsiDatabaseIsTablePersistent

The MsiDatabaseIsTablePersistent function returns an enumeration describing the state of a particular table.

MSICONDITION MsiDatabaseIsTablePersistent(
  MSIHANDLE hDatabase,   // database handle
  LPCTSTR szTableName    // name of relevant table
);

Parameters

hDatabase
[in] Handle to the database to which the relevant table belongs.
szTableName
[in] Specifies the name of the relevant table.

Return Values

MSICONDITION_ERROR
An invalid handle or invalid parameter was passed to the function.
MSICONDITION_FALSE
The table is temporary.
MSICONDITION_NONE
The table is unknown.
MSICONDITION_TRUE
The table is persistent.

Requirements

  Windows NT/2000/XP: Included in Windows 2000 and later.
  Windows 95/98/Me: Included in Windows Me.
  Redistributable: Requires Windows Installer 1.0 or later on Windows NT 4.0 SP3 and Windows 95/98.
  Header: Declared in Msiquery.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
