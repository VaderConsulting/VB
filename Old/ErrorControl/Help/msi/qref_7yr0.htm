MsiSetInstallLevel

The MsiSetInstallLevel function sets the installation level for a full product installation.

UINT MsiSetInstallLevel(
  MSIHANDLE hInstall,   // installer handle
  int iInstallLevel     // install level
);

Parameters

hInstall
[in] Handle to the installation.
iInstallLevel
[in] Specifies the installation level.

Return Values

ERROR_FUNCTION_FAILED
The function failed.
ERROR_INVALID_HANDLE
An invalid or inactive handle was supplied.
ERROR_SUCCESS
The function succeeded.

Remarks

The MsiSetInstallLevel function sets the following.

  • The installation level for the current installation to a specified value.
  • The Select and Installed states for all features in the Feature table.
  • The Action state of each component in the Component table, based on the new level.

If 0 or a negative number is passed in the ilnstallLevel parameter, the current installation level does not change, but all features are still updated based on the current installation level.

See Calling Database Functions From Programs.

Requirements

  Windows NT/2000/XP: Included in Windows 2000 and later.
  Windows 95/98/Me: Included in Windows Me.
  Redistributable: Requires Windows Installer 1.0 or later on Windows NT 4.0 SP3 and Windows 95/98.
  Header: Declared in Msiquery.h.
  Library: Use Msi.lib.
