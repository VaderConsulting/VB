MsiConfigureFeature

The MsiConfigureFeature function configures the installed state for a product feature.

UINT MsiConfigureFeature(
  LPCTSTR szProduct,          // product code
  LPCTSTR szFeature,          // feature ID
  INSTALLSTATE eInstallState  // install state
);

Parameters

szProduct
[in] Specifies the product code for the product to be configured.
szFeature
[in] Specifies the feature ID for the feature to be configured.
eInstallState
[in] Specifies the installation state for the feature. This parameter must be one of the following values.
Value Meaning
INSTALLSTATE_ADVERTISED The feature is advertised
INSTALLSTATE_LOCAL The feature is installed locally.
INSTALLSTATE_ABSENT The feature is uninstalled.
INSTALLSTATE_SOURCE The feature is installed to run from source.
INSTALLSTATE_DEFAULT The feature is installed to its default location.

Return Values

Value Meaning
ERROR_INVALID_PARAMETER An invalid parameter was passed to the function.
ERROR_SUCCESS The function succeeded.
An error relating to an action See Error Codes.
Any Initialization Error An error relating to initialization occurred.

Requirements

  Windows NT/2000/XP: Included in Windows 2000 and later.
  Windows 95/98/Me: Included in Windows Me.
  Redistributable: Requires Windows Installer 1.0 or later on Windows NT 4.0 SP3 and Windows 95/98.
  Header: Declared in Msi.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
