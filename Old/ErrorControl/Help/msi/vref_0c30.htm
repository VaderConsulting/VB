Platform SDK: Windows Installer

Windows Installer Object Model

The object model for the Windows Installer is organized as follows.

ComponentQualifiers, Components, Features, and Products are StringList collections, which are just an array of strings, such as a user-defined collection. These strings represent names of elements that are core to the installer.
