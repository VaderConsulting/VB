Platform SDK: Windows Installer

OpenView Method

The OpenView method of the Database object returns a View object representing the query specified by a SQL string.

object.OpenView(sql)

Parts

object
Database object
sql
Required SQL query string.

Remarks

For information about SQL syntax implemented in the installer, see SQL Syntax.
