Platform SDK: Windows Installer

PreventInstall Action

The PreventInstall action blocks the pending installation of a product if both the property set by the Upgrade table operator and the property in the Property column of the Upgrade table are set.

Sequence Restrictions

The PreventInstall action must come after the FindRelatedProducts action.

ActionData Messages

None.

Remarks

If the product is already installed and the action should therefore not execute, use a conditional expression of "NOT Installed" in the condition column of the table.

For more information about using the PreventInstall action in product upgrades, see Preparing an Application for Future Major Upgrades.
