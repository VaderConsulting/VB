Platform SDK: Windows Installer

P

package
A package consists of an .msi file and any external source files that may be pointed to by this file. A package therefore contains all the information the Microsoft Windows Installer needs to run the user interface and to install or uninstall the application. See also installer database.
package code
A package code is a GUID that identifies a particular package. A unique package code is required because some transforms or patch packages can be applied to more than one application or can upgrade an application into another application or version. See Package Codes.
patching
Patching is a method of updating a file that replaces only the bits being changed, rather than the entire file. This means that users can download an upgrade patch for a product that is much smaller than the entire product. See Patch Packages.
patch file
A patch package used for patching. See Patching and Upgrades.
preview mode
The installer provides a basic preview mode for viewing the design of the user interface. For more information about the preview mode, see Previewing the User Interface.
progress bar
A control the installer can display during script execution time representing the time progress of the installation. See Authoring a Progress Bar Control.
property
Properties are global variables used during an installation. (See About Properties.)

The term "property" also refers to an attribute of an automation object. (See Automation Interface.)

publishing
Publishing and assigning are methods of advertising a feature or application. Publishing does not populate the user interface. However, if an another application attempts to open a published application, there is enough information present for the installer to assign the published application. See also assigning. For more information, see Components and Features.
