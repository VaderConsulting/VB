Platform SDK: Windows Installer

CloseModule Function

The CloseModule function implements the CloseModule method of the Merge object. This function closes the currently open Windows Installer merge module.

IMsmMerge::CloseModule      All Mergemod.dll versions.

IMsmMerge2::CloseModule    Mergemod.dll version 2.0 or later.

HRESULT CloseModule();

Parameters

None

Return Values

Value Meaning
E_FAIL There was an error closing the module. The state of the IMsmMerge or IMsmMerge2 interface is now undefined.
S_FALSE No module was open.
S_OK The function succeeded.

Remarks

Closing a merge module does not affect any errors that have not been retrieved.
