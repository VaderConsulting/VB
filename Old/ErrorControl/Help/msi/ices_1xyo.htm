Platform SDK: Windows Installer

ICE40

ICE40 does miscellaneous validation.

Result

ICE40 posts warnings on the following:

  • The .msi file is missing the Error table and the Page Count Summary Property is less than or equal to 100. This means that the installer is only capable of displaying numeric error codes to the user at run time. The Error table is only required in packages having a schema that is less than or equal to 100. Windows Installer versions 1.1 and later do not require the package to have an Error table because the error messages can also be retrieved using Msimsg.dll. Packages with a schema greater than 100 cannot be installed by Windows Installer version 1.0.
  • The REINSTALLMODE property has been overridden.
  • The RemoveIniFile table has a Delete Tag entry with no value.

Example

Property Table

Property Value
REINSTALLMODE A

RemoveIniFile Table

RemoveIniFile Action Value
REINSTALLMODE 4  

Results

ICE40 would report the following errors.

ICE40 error Description
REINSTALLMODE is defined in the Property table. This may cause difficulties. Defining the REINSTALLMODE property in .msi file can lead to unexpected behavior.

To fix this error, don't define this property.
RemoveIniFile entry Remove1 must have a value, because the Action is "Delete Tag" (4). There is a Delete Tag action in the in the RemoveIniFile column of the RemoveIniFile table without specifying a tag to delete in the Value column.
Error Table is missing. Only numerical error messages will be generated. The .msi file is missing the Error table and the Page Count Summary Property is less than or equal to 100. This means that the installer is only capable of displaying numeric error codes to the user at run time.

To fix this error, add an Error table to the installation package and author formatting templates in the Message column for error messages.
