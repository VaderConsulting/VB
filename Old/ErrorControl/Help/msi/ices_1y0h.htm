ICE51

ICE51 checks for TTC/TTF fonts that have titles and other fonts that are missing titles.

You must specify a title for fonts that do not have embedded names.

TTF/TTC fonts have the title of the font embedded in the file itself. Do not specify a title for these fonts because the font is then registered twice, once under the supplied name and again under the embedded name.

Result

ICE51 posts an error or warning if there are any TTC/TTF fonts with titles or other fonts missing titles.

Example

ICE51 would report the following warning for the example shown.

Font 'Font1' is a TTC\TTF font, but also has a title.

ICE51 would report the following error message for the example shown.

Font 'Font2' does not have a title. Only TTC\\TTF fonts do not need titles.
