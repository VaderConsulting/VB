Platform SDK: Windows Installer

OpenLog Method

The OpenLog method of the Merge object opens a log file that receives progress and error messages. If the log file already exists, the installer appends new messages. If the log file does not exist, the installer creates a log file.

Syntax

object.OpenLog(Filename)

Parameters

object
Merge object
Filename
Fully qualified filename pointing to a file to open or create.

Remarks

Clients may send their own messages to this log file via the Log method.

See OpenLog function.
