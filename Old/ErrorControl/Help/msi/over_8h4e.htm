How do I determine the Windows Installer Version?

These methods can be used to determine the Windows Installer version.

  • Call MsiGetFileVersion with the szFilePath parameter set to the path to the file Msi.dll.
  • The four-field string in the above table is also equivalent to the Version Property (Installer Object).
  • Applications can get the Windows Installer version by using DllGetVersion.

For more information, see Released Versions of Windows Installer.
