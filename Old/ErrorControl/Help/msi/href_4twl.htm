Platform SDK: Windows Installer

PropertyValue Control Attribute

This attribute is the present value of the property displayed or changed by this control. If the Indirect bit is not set, this is the value of PropertyName. If the Indirect attribute bit is set, this is the value of IndirectPropertyName. If the attribute changes, the control reflects the new value.

String or Integer depending on the Integer attribute of the control.

Valid Controls

All active controls.

Associated Bit Flags

None.

Remarks

See Control Attributes and the control you need to create under Controls.
