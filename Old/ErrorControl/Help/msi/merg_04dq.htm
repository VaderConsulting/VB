Platform SDK: Windows Installer

OpenLog Function

The OpenLog function implements the OpenLog method of the Merge object. This function opens a log file that receives progress and error messages. If the log file already exists, the installer appends new messages. If the log file does not exist, the installer creates a log file.

IMsmMerge::OpenLog      All Mergemod.dll versions.

IMsmMerge2::OpenLog    Mergemod.dll version 2.0 or later.

HRESULT OpenLog(
BSTR FileName 
);

Parameters

FileName
[in] Fully qualified filename pointing to a file to open or create. A LPCWSTR may be used in place of a BSTR.

Return Values

Value Meaning
ERROR_TOO_MANY_OPEN_FILES as HRESULT There is already a log file open.
ERROR_OPEN_FAILED as HRESULT The file could not be opened or created.
S_OK The function succeeded.

Remarks

This function opens a log file to receive progress and error messages. If the log file already exists, new messages get appended to the log. If the log file does not exist it is created.

Clients may send their own messages to this log file using the Log Function.
