Embedded Transforms

Embedded transforms are stored inside the .msi file of the package. This guarantees to users that the transform is always available when the installation package is available. Alternatively, transforms may be provided to users as stand-alone .mst files.

To add an embedded transform to the transforms list, add a colon (:) prefix to the filename. Because the installer can always obtain the transform from storage in the .msi file, embedded transforms are not cached on the user's computer. Embedded transforms may be used in combination with secured transforms or unsecured transforms. For more information, see Applying Transforms.
