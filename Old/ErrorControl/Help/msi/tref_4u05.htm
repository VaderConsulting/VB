MsiAssembly Table

The MsiAssembly table specifies Windows Installer settings for .NET Framework assemblies and Win32® assemblies. For information, see, Installation of Assemblies to the Global Assembly Cache and Installation of Win32 Assemblies.

On Windows XP and later systems, Windows Installer version 2.0 and later can install Win32 assemblies as side-by-side assemblies. For more information, see About Isolated Applications and Side-by-side Assemblies.

The MsiAssembly table has the following columns.

Column Type Key Nullable
Component_ Identifier Y N
Feature_ Identifier   N
File_Manifest Identifier   Y
File_Application Identifier   Y
Attributes Integer   N

Columns

Component_
Key into the Component table specifying the Windows Installer component that contains this assembly. This component's KeyPath must not be the manifest file specified in File_Manifest.
Feature_
Key into the Feature table. When the assembly has to be installed by a feature installation, Windows Installer installs the feature pointed to by this field.
File_Manifest
An external key into the File table specifying the file that contains the manifest for a .NET Framework assembly. Do not specify this file as the component's key path file in the KeyPath field of the Component table.
File_Application
Enter a value in this field to install a .NET Framework or Win32 assembly for the private use of a particular application. The value in this field is an external key into the File table. The installer uses the directory structure specified in the Directory table to install the assembly into the same directory as the component containing this file. This field must be Null if the assembly is to be installed into the global assembly cache.
Attributes
Enter a value of 1 for a Win32 assembly and a value of 0 for a .NET Framework assembly.

Remarks

If there is at least one entry in the MsiAssembly table, the InstallExecuteSequence table must contain the MsiPublishAssemblies action and MsiUnpublishAssemblies action.
