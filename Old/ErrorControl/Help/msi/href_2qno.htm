SelectionDescription ControlEvent

The SelectionTree control uses the SelectionDescription event to publish a string that contains the description for the highlighted item. This string is the Description field of the Feature Table.

Published By

SelectionTree

Argument

None.

Action on Subscribers

None.

Typical Use

A Text control on the same modal dialog as the SelectionTree uses this event to display the description of the highlighted item.
