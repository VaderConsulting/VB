How do I advertise a per-user application to be installed with elevated privileges?

Adhere to the following points to advertise an application on a per-user installation basis when the application requires elevated (system) privileges for installation. This advertises the application to the specified user, and when they choose install, will install the application with elevated privileges.

  • Your process must be a service running under the LocalSystem system account on Windows 2000 or a later operating system.
  • Generate an advertise script by calling MsiAdvertiseProduct or MsiAdvertiseProductEx.
  • Your process must impersonate the user that is the target for the advertisement.
  • Call MsiAdvertiseScript, and use the flags SCRIPTFLAGS_CACHEINFO | SCRIPTFLAGS_REGDATA_APPINFO | SCRIPTFLAGS_REGDATA_CNFGINFO | SCRIPTFLAGS_SHORTCUTS.
