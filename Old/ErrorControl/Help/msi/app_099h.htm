Platform SDK: Windows Installer

Msizap.exe

Msizap.exe is a command line utility that removes all Windows Installer information for a product or all products installed on a computer. Products installed by the installer may fail to function after using MsiZap.

MsiZap.exe does not require any special privileges to run on Windows 95/98/Me platforms. On Windows NT, Windows 2000, and Windows XP, administrative privileges are required to use MsiZap.exe.

Syntax

msizap T[WA!] {product code}
msizap T[WA!] <msi package>
msizap *[WA!] ALLPRODUCTS
msizap PWSA?!

Command Line Options

Msizap.exe uses the following case-insensitive command line options.

Option Description
* Remove all Windows Installer folders and registry keys, adjust shared DLL counts, and stop Windows Installer service. Also removes the In-Progress key and rollback information.
a Only change ACLs to Admin Full Control for any specified removal.
p Remove the In-Progress key.
s Remove Rollback Information.
t Remove all information for the specified product code. When using this option, enclose the Product Code in curly braces. This option may be used with either the full path to the .msi file or with the product code.
w Remove Windows Installer information for all users. When this option is not set, only the information for the current user is removed. Use of this option requires that the user's profile be loaded so that the user's per-user registry hive be available.
? Verbose help.
! Force a 'yes' response to any prompt.
