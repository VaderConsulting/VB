MsiAdvertiseProductEx

The MsiAdvertiseProductEx function generates an advertise script or advertises a product to the computer. The MsiAdvertiseProductEx function enables the installer to write to a script the registry and shortcut information used to assign or publish a product. Provides the same functionality as MsiAdvertiseProduct. The script can be written to be consistent with a specified platform by using MsiAdvertiseProductEx.

UINT MsiAdvertiseProductEx(
  LPCTSTR szPackagePath,     // location of package
  LPCTSTR szScriptfilePath,  // if NULL, product is locally advertised
  LPCTSTR szTransforms,      // list of transforms to be applied
  LANGID lgidLanguage,       // install language
  DWORD dwPlatform,          // the MSIARCHITECTUREFLAGS that control
                             // for which platform to create the script,
                             // ignored if szScriptfilePath is NULL
  DWORD dwReserved           // reserved for future use, must be 0
);

Parameters

szPackagePath
[in] The full path to the package of the product being advertised.
szScriptfilePath
[in] The full path to script file to be created with the advertise information. To advertise the product locally to the computer, set ADVERTISEFLAGS_MACHINEASSIGN or ADVERTISEFLAGS_USERASSIGN.
Flag Value Meaning
ADVERTISEFLAGS_MACHINEASSIGN 0 Set to advertise a per-machine installation of the product available to all users.
ADVERTISEFLAGS_USERASSIGN 1 Set to advertise a per-user installation of the product available to a particular user.

szTransforms
[in] A semi-colon delimited list of transforms to be applied. This parameter may be Null.
lgidLanguage
[in] The language to use if the source supports multiple languages.
dwPlatform
[in] Bit flags that control which specify for which platform the installer should create the script. This parameter is ignored if szScriptfilePath is Null. If dwPlatform is 0, then the script is created based on the current platform. This is the same functionality as MsiAdvertiseProduct. If dwPlatform is 1 or 2, the installer creates script for the specified platform.
Flag Value Meaning
none 0 Create a script for the current platform.
MSIARCHITECTUREFLAGS_X86 1 Create a script for the x86 platform.
MSIARCHITECTUREFLAGS_IA64 2 Create a script for the IA64 platform.

dwReserved
[in] Reserved for future use. This parameter must be 0.

Return Values

Value Meaning
ERROR_SUCCESS The function completed successfully.
An error relating to an action See Error Codes.
Any Initialization Error An error relating to initialization occurred.
ERROR_CALL_NOT_IMPLEMENTED This error is returned if an attempt is made to generate an advertise script on any platform other than Windows 2000 or Windows XP. Advertisement locally to the computer is supported on all platforms.

Remarks

Available with Windows Installer version 2.0 and later versions.

Requirements

  Windows NT/2000/XP: Included in Windows XP and Windows .NET Server.
  Redistributable: Requires Windows Installer 2.0 on Windows NT 4.0 SP6; Windows 2000; and Windows Me.
  Header: Declared in Msi.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
