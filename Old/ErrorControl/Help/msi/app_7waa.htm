Platform SDK: Windows Installer

Released Versions of Windows Installer

The follow table lists the released versions of the Microsoft® Windows® Installer. For more information about the value of operating system properties, see Operating System Property Values.

Released Version Version Description
Windows Installer 1.0 1.00.5104.0 Released with Office 2000 and as a redistributable.
Windows Installer 1.1 1.10.1029.0 Released with Windows 2000.
1.10.1029.1 Released as a redistributable.
Windows Installer 1.11 1.11.1314.0 Released with Windows 2000 Service Pack 1.
Windows Installer 1.2 1.20.1410.0 Released with Windows Millennium Edition.
  1.20.1827.1 Released as a redistributable.
Windows Installer 2.0 2.0.2526.0 or later Latest Windows Installer version

To determine the Windows Installer version, call MsiGetFileVersion with the szFilePath parameter set to the path to the file Msi.dll. Applications can get the Windows Installer version by using DllGetVersion. For information, see How do I determine the Windows Installer Version?

The four-field string in the above table is also equivalent to the Version Property (Installer Object).

You can obtain the latest Windows Installer redistributable from the Platform SDK Redistributables site at http://www.microsoft.com/msdownload/platformsdk/sdkupdate/psdkredist.htm
