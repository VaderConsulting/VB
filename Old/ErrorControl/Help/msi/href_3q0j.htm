Platform SDK: Windows Installer

Control Events

A ControlEvent specifies an action to be taken by the installer or a change in the attributes of one or more controls in a dialog box. For more information about ControlEvents, see ControlEvent Overview.

The following list provides links to more information about particular ControlEvents:

Control event Brief description of control event
ActionData Publishes data on the latest action.
ActionText Publishes the name of the present action.
AddLocal Notifies the installer to run features locally.
AddSource Notifies the installer to run features from source.
CheckExistingTargetPath Notifies installer to verify that path can be written.
CheckTargetPath Notifies installer to verify that path is valid.
DirectoryListNew Notifies DirectoryList control to create new folder.
DirectoryListOpen ControlEvent Selects directory in the DirectoryList control.
DirectoryListUp Notifies DirectoryList control to select parent of the present directory.
DoAction Dialog box notifies installer to execute custom action.
EnableRollback ControlEvent Used to turn rollback capabilities off and on.
EndDialog Notifies installer to remove a modal dialog box.
IgnoreChange Published by the DirectoryList control when a folder is highlighted but not opened.
NewDialog Notifies installer to change a modal dialog box into another dialog box.
Reinstall Initiates a reinstall of features.
ReinstallMode Specifies the validation mode during a reinstall.
Remove Notifies installer when features are selected for removal.
Reset Resets all the property values to when the dialog was created.
ScriptInProgress Displays a string while execution script is compiled.
SelectionAction Published by SelectionTree to describe an item.
SelectionBrowse Published by SelectionTree to spawn browse dialog.
SelectionDescription Publish by SelectionTree to provide string in Description field of Feature Table.
SelectionIcon Published by SelectionTree to provide icon handle.
SelectionNoItems ControlEvent Used by SelectionTree to delete text or disable buttons.
SelectionPath Published by SelectionTree to provide path of item.
SelectionPathOn Published by SelectionTree to indicate whether there is a path associated with a feature.
SelectionSize Published by SelectionTree control to provide size of the item.
SetInstallLevel Installer changes installation level to specified value.
SetProgress Published by installer to provide installation progress.
SetProperty Sets a specified property.
SetTargetPath Notifies installer to check and set a path.
SpawnDialog Notifies installer to create a child of a modal box.
SpawnWaitDialog Triggers a specified dialog.
TimeRemaining Published by installer to provide time remaining in the progress sequence.
ValidateProductID Sets ProductID to the full Product ID.
