Platform SDK: Windows Installer

TRANSFORMSATSOURCE Property

When using Windows Installer version 1.0, setting the TRANSPORMSATSOURCE property to 1 informs the installer that the location of transforms is at the root of the source of the installation package. If this property is set for a transform, the installer prefixes the @ symbol to that transform's filename in the transform list. The transform list is the value of the TRANSFORMS property. The installer then locates that transform, and all subsequent transforms in the list, at the root of the source where the .msi file is located.

Setting this property is like setting the TransformsAtSource policy except that the scope is different. Setting TransformsAtSource policy applies to all packages installed by a given user. Setting the TRANSFORMSATSOURCE property applies to the package regardless of the users.

Remarks

This property and policy are not available with Windows Installer version 1.1. Windows Installer version 1.1 interprets the TRANSFORMSATSOURCE property as though it were the TRANSFORMSSECURE property. If the @ flag is passed in the TRANSFORMS property, Windows Installer version 1.1 treats the transforms in the list as secure-at-source transforms.
