Platform SDK: Windows Installer

I

IAT
See import address table.
.idt file
An .idt file is an exported installer database table. See Importing and Exporting and Windows Installer File Extensions.
import address table
The location where the computed virtual address from each function that is imported from all DLLs is saved.
internal user interface
The built-in capabilities of the installer that can be used to author a graphical user interface for the installation process. An author may alternatively choose using an external user interface. For more information, see About The User Interface.
install level
For any installation, there is a specified install level value. An application is installed only if its own level is less than or equal to the install level. The set of applications chosen for installation can therefore be changed by altering the install level. For more information about the install level, see the discussion at Feature table.
installation-on-demand
An installer service that installs applications or features only when they are requested by the user or another application. Advertising makes a feature or application available for install-on-demand installation. For more information, see: Installation-On-Demand.
installer
The Microsoft Windows Installer.
installer database
A relational database containing all the setup instructions for an installation. The installer database is stored in the .msi file. For more information about the installer database, see Installer Database.
installer function
A function called by a user or application to obtain installer services and functionality. This is the application programming interface of the installer. For information about installer functions, see Installer Function Reference.
installer package authoring tool
Software that enables a developer to create and edit an .msi file. This together with any external source files comprise a package containing all the information required for an installation.
internal source files
Source files for the application being installed that are stored in the .msi file. Multiple internal source files can be compressed and stored together in a cabinet file that is stored within an .msi file.
