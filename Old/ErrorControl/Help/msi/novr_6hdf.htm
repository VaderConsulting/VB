Platform SDK: Windows Installer

Naming Custom Tables, Properties and Actions

Starting with Windows Installer version 2.0, all new native Windows Installer properties, actions, and tables are given names prefixed by Msi. This prefix is not case sensitive, for example MsiNewInternalTable.

A package author can ensure that the names of any custom tables, properties, or actions in his package will not conflict with future versions of the Windows Installer by not using new names beginning with Msi. Because the prefix is not case sensitive, authors should avoid all cases of the msi prefix. To prevent conflict with versions earlier than Windows Installer version 2.0, authors should use their own prefix created for use with their custom properties, actions, and tables.

For more information, see Table Names.
