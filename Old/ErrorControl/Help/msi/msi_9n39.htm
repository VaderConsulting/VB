MsiOpenPackage

The MsiOpenPackage function opens a package for use with the functions that access the product database. The MsiCloseHandle function must be called with the handle when the handle is no longer needed.

UINT MsiOpenPackage(
  LPCTSTR szPackagePath,  // the full path to the package
  MSIHANDLE *hProduct     // returned product handle, must be closed
);

Parameters

szPackagePath
[in] Specifies the path to the package.
hProduct
[out] Pointer to a variable that receives the product handle.

Return Values

Value Meaning
ERROR_BAD_CONFIGURATION The configuration information is corrupt.
ERROR_INSTALL_FAILURE The product could not be opened.
ERROR_INVALID_PARAMETER An invalid parameter was passed to the function.
ERROR_SUCCESS The function completed successfully.

If this function fails, it may return a system error code. For more information, see System Error Codes.

Remarks

MsiOpenPackage can accept an opened database handle in the form "#nnnn", where nnnn is the database handle in string form, i.e. #123, in lieu of a path to the package. This is intended for development tasks such as running validation actions, or for use with database management tools.

Requirements

  Windows NT/2000/XP: Included in Windows 2000 and later.
  Windows 95/98/Me: Included in Windows Me.
  Redistributable: Requires Windows Installer 1.0 or later on Windows NT 4.0 SP3 and Windows 95/98.
  Header: Declared in Msi.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
