Platform SDK: Windows Installer

Bitmap Control

This control displays a static picture of a bitmap.

Control Attributes

You can use the following attributes with this control. To change the value of an attribute using an event, subscribe the control to a ControlEvent in the EventMapping table and list the attribute's identifier in the Attribute column. Enter the Identifier of the ControlEvent in the Event column.

Attribute identifier Hexadecimal bit Description
Position Position of control in the dialog box.

Enter the control's width, height, and coordinates of the control's left corner into the Width, Height, X, and Y columns of the Control table or BBControl table. Use installer units for length and distance.
Text Contains the name of a bitmap stored in the Binary table or the handle to a bitmap or icon loaded into memory at run-time.

To display a bitmap that is stored in the Binary table, do not set the ImageHandle attribute and enter the name of the image's record appearing in the Binary table into the Text column of the Control table record for this control.

To set the bitmap image at run-time, set the ImageHandle control attribute in the Attributes of the Control table. At run-time, the Text control attribute is the handle to a bitmap loaded into memory. The control must subscribe to a control event listed in the EventMapping table with the Text control attribute specified in the Attribute column.

Sunken 0x00000000

0x00000004

 Display the default visual style.

Display the control with a sunken, 3-D look.

Include these bits in the bit word in the Attributes column of the Control table.
ImageHandle 0x00000000

0x00010000

 See the description of the Text control attribute for this control. If the ImageHandle attribute is included in the Attributes column of the Control table, the Text control attribute contains a handle to a bitmap that is loaded into memory at run-time. If the ImageHandle attribute is not included in Attributes, the Text Control attribute is the name of the bitmap image and must be authored into the Text column of the Control table. This name is a key into the record of the Binary table containing the bitmap image.
FixedSize Control 0x00000000

Include this bit in the bit word of the Attributes column of the BBControl table or the Control table.


Remarks

This control is created as a "STATIC" with the SS_BITMAP, SS_CENTERIMAGE, WS_CHILD, and WS_GROUP styles.
