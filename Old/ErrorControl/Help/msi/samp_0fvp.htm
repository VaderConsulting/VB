Platform SDK: Windows Installer

Establish an HTML Reference to Setup.exe

The final step is to place a reference to the Setup.exe on the hypothetical MySetup Web page (MySetup.html) described in A URL Based Windows Installer Installation Example. Use the following HTML script:

<a href="http://www.example.com/Products/MySetup/setup.exe">MySetup Installation</a>

Clicking on the "MySetup Installation" link presents users with the option to save or run from that location. If the user selects run from that location, the Setup.exe upgrades the version of the Windows Installer on the computer, if necessary, verifies the digital signature on the Windows installer package, and installs the package on their computer.

This completes the example.
