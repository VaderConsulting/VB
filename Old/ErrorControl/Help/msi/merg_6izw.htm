How do I add module configuration capability to a merge tool?

To enable end users to use configurable merge modules, developers should author merge and configuration tools to do the following:

  • Merge tools should call the functions in Mergemod.dll version 2.0 to merge the module. Earlier versions of Mergemod.dll cannot be used to configure merge modules.
  • Client configuration applications should interact with the merge module user to collect the user's selections for configurable items.
  • Merge tools should expose configuration information authored into the merge module to the client application so that the client may use this information to query the user.
  • When a merge tool encounters a configurable item during the merge, it should call the client configuration tool for customization information obtained from the user. The merge tool should make the specified changes to the merge module.
  • Configuration applications should enable the user to provide choices for configurable items, but they do not need to reveal all the possible choices to the user. It may use default values for configurable items not selected by the user.
  • If a user declines to provide customization information, merge tools should use the default configuration values specified in the merge module .
  • After the user gives the configuration tool his or her selections, the merge tool calls Mergemod.dll to perform the merge.
