CloseLog Function

The CloseLog function implements the CloseLog method of the Merge object. This function closes the current log.

IMsmMerge::CloseLog      All Mergemod.dll versions.

IMsmMerge2::CloseLog    Mergemod.dll version 2.0 or later.

HRESULT CloseLog();

Parameters

This function has no parameters.

Return Values

Value Meaning
E_FAIL There was an error closing the log file.
S_FALSE No log file was open.
S_OK The function succeeded.
