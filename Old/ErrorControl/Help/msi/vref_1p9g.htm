Platform SDK: Windows Installer

ReinstallFeature Method

The ReinstallFeature method reinstalls features or corrects problems with installed features.

object.ReinstallFeature Product, Feature, ReinstallMode

Parts

object
Installer object
Product
Specifies the product code of the product.
Feature
Identifies the feature to be reinstalled.
ReinstallMode
Specifies the type of reinstallation. This parameter can be one or more of the following values.
Value Meaning
msiReinstallModeFileMissing Reinstall only if the file is missing.
msiReinstallModeFileOlderVersion Reinstall if the file is missing or is an older version.
msiReinstallModeFileEqualVersion Reinstall if the file is missing or is an equal or older version.
msiReinstallModeFileExact Reinstall if the file is missing or is not an exact version.
msiReinstallModeFileVerify Check sum executables, and reinstall if they are missing or corrupt.
msiReinstallModeFileReplace Reinstall all files regardless of version.
msiReinstallModeUserData Ensure required per-user registry entries.
msiReinstallModeMachineData Ensure required per-machine registry entries.
msiReinstallModeShortcut Validate shortcuts.
msiReinstallModePackage Use the re-cache source to install the package.
