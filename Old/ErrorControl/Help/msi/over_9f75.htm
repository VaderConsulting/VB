Source Resiliency Policy - Windows Installer Version 1.1

The installer begins searching for a source by checking the most recently used source location in the source list, then the list of network sources, then media sources, and finally URL sources. For more information, see Source Resiliency. If the search fails, the installer presents a Browse Dialog enabling the user to search for the source manually. The browse dialog cannot be displayed if the user interface levels is set to None. An administrator controls the display of the browse dialog to users by setting system policy.

With Windows Installer version 1.1, administrators should secure managed applications by setting the DisableMedia policy, the DisableBrowse policy, and by omitting the "m" option from the SearchOrder policy. This prevents non-administrators from using the browse dialog to search for sources located on media, and prevents non-administrators from using these sources to install managed applications. An administrator can enable a non-administrator to browse or install managed applications from media by using the AllowLockdownBrowse and AllowLockdownMedia policies. Note that setting the DisableMedia policy does not prevent first-time installation from sources located on media, it only prevents users from installing from media sources during maintenance installations.
