What's New in Windows Installer Version 2.0

The following list outlines additions and changes to Microsoft® Windows® Installer available in Windows Installer version 2.0 or later.

Windows Installer version 2.0 requires Microsoft Windows NT® 4.0 with Service Pack 6 or later, Microsoft Windows® 2000, Microsoft Windows Millennium Edition (Windows Me), or Microsoft Windows XP. Earlier Windows Installer versions require Windows NT 4.0 with Service Pack 3 or later, Windows 2000, or Windows Me.

Note  Starting with Windows Installer version 2.0, the following features are in effect:

  • You can install 64-bit Windows Installer packages. A 64-bit package is indicated by entering the value Intel64 in the Template Summary Property. The schema of a 64-bit package must be 200 or greater. Therefore the Page Count Summary Property of a 64-bit package must be 200 or greater. If a version of Windows Installer earlier than version 2.0 is called to install a 64-bit package, it returns the following error requesting that the user update the Windows Installer: ERROR_INSTALL_PLATFORM_UNSUPPORTED – "This installation package is not supported on this platform. Contact your application vendor."
  • The installer adds debugging information to the installation log file for custom action scripts.
  • A component may be added to an existing feature by an update or patch without a required product code change. For more information, see Changing the Product Code.
  • Minor upgrades are no longer required to install new child features by using the ADDLOCAL property. Instead new child features can be authored by including msidbFeatureAttributesFollowParent and msidbFeatureAttributesUIDisallowAbsent in the Feature table. For more information, see Controlling Feature Selection States.
