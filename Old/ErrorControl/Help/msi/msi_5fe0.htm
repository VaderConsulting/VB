Platform SDK: Windows Installer

MsiApplyPatch

For each product listed by the patch package as eligible to receive the patch, the MsiApplyPatch function invokes an installation and sets the PATCH property to the path of the patch package.

UINT MsiApplyPatch(
  LPCTSTR szPatchPackage,    // location of the patch package
  LPCTSTR szInstallPackage,  // location of product to be patched 
                             // <optional>
  INSTALLTYPE eInstallType,  // type of install to patch
  LPCTSTR szCommandLine      // command line <property settings>
);

Parameters

szPatchPackage
Specifies the full path to the patch package.
szInstallPackage
Specifies a path to the product that is to be patched if eInstallType is set to INSTALLTYPE_NETWORK_IMAGE. The installer applies the patch to every eligible product listed in the patch package if szInstallPackage is set to 0 and eInstallType is set to INSTALLTYPE_DEFAULT.
eInstallType
This parameter specifies the type of installation to patch. A value of 1 for INSTALLTYPE_NETWORK_IMAGE sets this for a administrative installation. The eInstallType parameter is ignored if szInstallPackage is omitted.
Type of installation Meaning
INSTALLTYPE_NETWORK_IMAGE Indicates a administrative installation. In this case, szInstallPackage must be set to a package path.
INSTALLTYPE_DEFAULT Searches system for products to patch. In this case, szInstallPackage must be 0.

szCommandLine
Specifies command line property settings. See About Properties.

Return Values

Value Meaning
ERROR_SUCCESS The function completed successfully.
ERROR_PATCH_PACKAGE* These errors may indicate an error with the patch package.
An error relating to an action See Error Codes.
Any Initialization Error An error relating to initialization occurred.

Remarks

Because the list delimiter for transforms, sources and patches is a semicolon, this character should not be used for filenames or paths.

Requirements

  Windows NT/2000/XP: Included in Windows 2000 and later.
  Windows 95/98/Me: Included in Windows Me.
  Redistributable: Requires Windows Installer 1.0 or later on Windows NT 4.0 SP3 and Windows 95/98.
  Header: Declared in Msi.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
