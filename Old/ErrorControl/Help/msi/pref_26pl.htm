Platform SDK: Windows Installer

DISABLEROLLBACK Property

Setting the DISABLEROLLBACK property disables the rollback option for the current configuration. Set this property to 1 to prevent the installer from generating a rollback script and saving copies of deleted files during the installation.

Default Value

By default, rollback is enabled.

Remarks

Setting this property has the same effect as setting the DisableRollback policy value to 1. For more information about DisableRollback policy, see System Policy.

The installer sets the RollbackDisabled Property whenever the DISABLEROLLBACK property is set to 1.

It is recommended that rollback not be disabled unless necessary because doing so can result in partially installed applications being left behind on a user's computer.
