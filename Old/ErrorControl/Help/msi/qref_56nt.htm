Platform SDK: Windows Installer

MsiSetProperty

The MsiSetProperty function sets the value for an installation property.

UINT MsiSetProperty(
  MSIHANDLE hInstall,   // installer handle
  LPCTSTR szName,       // property identifier, case-sensitive
  LPCTSTR szValue       // property value, NULL to undefine property
);

Parameters

hInstall
[in] Handle to the installer.
szName
[in] Specifies the name of the property.
szValue
[in] Specifies the value of the property.

Return Values

ERROR_FUNCTION_FAILED
The function failed.
ERROR_INVALID_HANDLE
An invalid or inactive handle was supplied.
ERROR_INVALID_PARAMETER
An invalid parameter was passed to the function.
ERROR_SUCCESS
The function succeeded.

Remarks

If the property is not defined, it is created by the MsiSetProperty function. If the value is NULL or an empty string, the property is removed.

Requirements

  Windows NT/2000/XP: Included in Windows 2000 and later.
  Windows 95/98/Me: Included in Windows Me.
  Redistributable: Requires Windows Installer 1.0 or later on Windows NT 4.0 SP3 and Windows 95/98.
  Header: Declared in Msiquery.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
