Major Upgrades

A major upgrade is a comprehensive update of the product that warrants a change in the ProductCode property. A major upgrade can be shipped as a patch package or as a full product installation package. Major upgrades are available in Microsoft® Windows® Installer version 1.1 and later versions. Installer version 1.0 does not support updates that change the product code.

During a major upgrade using Windows Installer version 1.1 or later, the installer searches the user's computer for applications that are related to the pending upgrade, and upon detecting one, retrieves the version of the installed application from the system registry. The installer then uses information in the upgrade's database to determine whether to upgrade the installed application.

To fully enable the installer's upgrade capabilities, every package should have an UpgradeCode property and an Upgrade table. Each record in the Upgrade table gives a combination of upgrade code, product version, and language information used to identify a set of products affected by the upgrade. When the FindRelatedProducts action detects that an affected product is installed on the system, it appends the product code to a property in the ActionProperty column of the Upgrade table. The RemoveExistingProducts action and the MigrateFeatureStates action remove or migrate the products listed in the ActionProperty list.

Note that Windows Installer uses only the first three fields of the product version. See ProductVersion property. If you include a fourth field in your product version, the installer ignores the fourth field.

Because Windows Installer version 1.1 supports upgrades that change the product code, package authors using earlier installer versions should follow the procedure described in Preparing an application for future major upgrades. This procedure ensures that an installation performed with Windows Installer version 1.0 is capable of using the upgrade capabilities of later installer versions.

For information on how to apply a major upgrade patch package to a Windows Installer package, see Major Upgrades by Patching the Local Installation of the Product, Major Upgrades by Reinstalling the Product, and Major Upgrades by Patching an Administrative Image.
