Platform SDK: Windows Installer

TransformsAtSource

If this per-user system policy is set to "1"; the installer searches for transform files in the root of any network sources in the source list for the product. By default, transforms are stored in the Application Data folder of a user's profile.

Registry Key

HKEY_CURRENT_USER\Software\Policies\Microsoft\Windows\Installer

Data Type

REG_DWORD

Remarks

Setting this property with Windows Installer version 1.0 is similar to setting the TRANSFORMSATSOURCE property except that the scope is different. Setting TransformsAtSource policy applies to all packages installed by a given user. Setting the TRANSFORMSATSOURCE property applies to the package regardless of the users.

This policy and property are not available with Windows Installer version 1.1. Windows Installer version 1.1 interprets the TransformsAtSource policy to be the same as the TransformsSecure policy.
