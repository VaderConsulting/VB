Custom Action Return Processing Options

The following option flags can be used to control the processing of the custom action thread. They are used to specify that the main and custom action threads run synchronously (the installer waits for the custom action thread to complete before resuming the main installation thread) or asynchronously (the installer runs the custom action simultaneously as the main installation continues).

To enable these options add the value indicated in this table to the value in the Type field of the CustomAction table.

Constant Hexadecimal Decimal Description
(none) 0x00000000 +0 Synchronous execution. Fails if exit code not 0. If the flag msidbCustomActionTypeContinue is not set then the custom action must return one of the return values described in Custom Action Return Values.
msidbCustomActionTypeContinue 0x00000040 +64 Synchronous execution. Ignores exit code and continues.
msidbCustomActionTypeAsync 0x00000080 +128 Asynchronous execution. Waits for exit code at sequence end.

This option cannot be used with Nested Installation Actions or Rollback Custom Actions.
msidbCustomActionTypeAsync + msidbCustomActionTypeContinue 0x00000040 + 0x00000080 +192 Asynchronous execution. No wait for completion. Execution continues after installer terminates.

This option cannot be used with Nested Installation Actions.
