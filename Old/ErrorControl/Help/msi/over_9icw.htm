Source Resiliency Policy - Windows Installer Version 2.0

The installer begins searching for a source by checking the most recently used source location in the source list, then the list of network sources, then media sources, and finally URL sources. For more information, see Source Resiliency. If the search fails, the installer may present a Browse Dialog enabling the user to search for the source manually. The browse dialog cannot be displayed if the user interface levels is set to None. An administrator controls the display of the browse dialog to users by setting system policy.

With Windows Installer version 2.0, non-administrators by default cannot use the browse dialog to locate managed application sources on media and cannot install managed applications. An administrator enables a non-administrator to browse or install managed applications from media by using the AllowLockdownBrowse and AllowLockdownMedia policies. An administrator disables the capability to browse or install applications from media by using the DisAbleBrowse and DisAbleMedia policies.
