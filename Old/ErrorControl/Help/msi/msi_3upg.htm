MsiGetShortcutTarget

The MsiGetShortcutTarget function examines a shortcut and returns its product, feature name, and component if available.

UINT MsiGetShortcutTarget(
  LPCTSTR szShortcutTarget,    // path to shortcut link file
  LPTSTR szProductCode,        // fixed length buffer for product code
  LPTSTR szFeatureId,          // fixed length buffer for feature id
  LPTSTR szComponentCode,      // fixed length buffer for component code
);

Parameters

szShortcutTarget
[in] The full path to a shortcut.
szProductCode
[out] A GUID for the product code of the shortcut, if available. Can be NULL.

Size: cchProductCode + 1.

szFeatureId
[out] The feature name of the shortcut, if available. Can be NULL.

Size: cchMaxFeatureName + 1.

szComponentCode
[out] A GUID of the component code, if available. Can be NULL.

Size: cchComponentId + 1.

Return Values

If return buffers are provided, they must be large enough for the return values and a terminating NULL, as defined in Msi.h.

ERROR_SUCCESS
The function succeeded.
ERROR_FUNCTION_FAILED
The function failed.

Remarks

If the function fails, and the shortcut exists, the regular contents of the shortcut may be accessed through the IShellLink interface.

Otherwise, the state of the target may be determined by using the Installer Selection Functions.

Requirements

  Windows NT/2000/XP: Included in Windows 2000 and later.
  Windows 95/98/Me: Included in Windows Me.
  Redistributable: Requires Windows Installer 1.1 or later on Windows NT 4.0 SP3 and Windows 95/98.
  Header: Declared in Msi.h.
  Library: Use Msi.lib.
  Unicode: Implemented as Unicode and ANSI versions on all platforms.
