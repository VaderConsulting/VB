Platform SDK: Windows Installer

ProductInfo Property

The ProductInfo property is a read-only property that returns the value of the specified attribute for an installed or published product.

object.ProductInfo(Product, Attribute)

Parts

object
Installer object
Product
Specifies the product code of the installed product that contains the attribute of interest.
Attribute
Identifies the attribute to be retrieved. The properties in the following list can only be retrieved from applications that are installed.
Property name Description
HelpLink Support link. See ARPHELPLINK property.
HelpTelephone Support telephone. See ARPHELPTELEPHONE property.
InstallDate Installation date.
InstallLocation Installation location. See ARPINSTALLLOCATION property.
InstalledProductName Installed product name. See ProductName property.
InstallSource Installation source. See SourceDir property.
LocalPackage Local cached package
ProductID The product identifier for the product.
Publisher Publisher. See Manufacturer property.
PackageName Name of the original installation package.
RegCompany Company registered to use this product.
RegOwner Individual registered to use this product.
URLInfoAbout URL information. See ARPURLINFOABOUT property.
URLUpdateInfo URL update information. See ARPURLUPDATEINFO property.
VersionMinor Minor product version derived from ProductVersion property.
VersionMajor Major product version derived from ProductVersion property.
VersionString Product version. See ProductVersion property.

The attributes in the following list can be retrieved from applications that are advertised.
Property Name Description
Transforms Transforms
Language Product language
AssignmentType Equals 0 if product is advertised or installed per-user.

Equals 1 if product is advertised or installed per-machine for all users.
PackageCode Identifier of package product was installed from. See Package Codes.
PackageName Name of the original installation package.
ProductIcon Primary Icon for the package. See ARPPRODUCTICON property.
ProductName Human readable product name. See ProductName property.
Version Product

version derived from ProductVersion property.

Remarks

ProductInfo("LocalPackage") does not necessarily return a path to the cached package. Maintenance mode installations should be not be invoked from the LocalPackage. The cached package is for internal uses only.
