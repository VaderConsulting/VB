About
------
    These are the test scripts, showing different TriggerTypes
    and modes of using this object. Can make reports about Mstask
    JOB files, or give your scripts additional state variables by
    looking up JOB status flags, etc.

	File- mscheduler.zip
	From- http://home.sprintmail.com/~mpryor/tasksch.htm
	
Contact
--------
	Author- Mark Pryor mpryor@sprintmail.com	

Note
-------
    These are all WSH V5.1+ scripts, written in XML format. If you
    want to use an unstructured VBS script, you can "include" SchAgent.inc.
	
Purpose
-------
	Configure your scheduled tasks from the a command-line
	script without using the Mstask interface to the Shell.
	Once you have correct logic in your script, you can see
	changes from the Mstask interface.
