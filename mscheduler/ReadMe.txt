Usage
------
	Copy the DLL to your system folder and run: 
		regsvr32.exe c:\windows\system\TaskScheduler.dll

	There is no help file, but the Archive contains a sample
	VBScript and a VB test module. Study the object in your
	favorite Object Browser.
	
Purpose
-------
	Configure your scheduled tasks from the a command-line
	script without using the Mstask interface to the Shell.
	Once you have correct logic in your script, you can see
	changes from the Mstask interface.
